# BLE In Action 執筆スタイルガイド（クイックリファレンス）

**バージョン**: 2.1.0 ／ **最終更新**: 2026-06-20
**位置づけ**: 本書**固有**の表記・用語・Markdown/Pandoc書式の正本。執筆理念は [book-constitution.md](book-constitution.md)、読者層別Noteは [writing-guidelines-reader-notes.md](writing-guidelines-reader-notes.md) を参照。

## 文体・表記

- **です・ます調**（「である」「だ」は不可）
- カッコの使い分け:
  - 「」… 日本語の引用・強調
  - "" … 英語・技術用語の引用
  - () … 正式名称・読みの補足（例: `BLE (Bluetooth Low Energy)`）
  - [] … 参考文献番号
- 数値と単位の間にスペース: `100 ms` `2.4 GHz` `-20 dBm`（例外: `95%` は直付け）

## 技術用語・カタカナ

- BLE標準用語は英語のまま。**初出時のみ**日本語併記: `GATT (Generic Attribute Profile、汎用属性プロファイル)`
- API名・プロトコル名・型名は英語のまま: `startAdvertising()`, GATT, Characteristic, Service, Descriptor
- 動作・概念はカタカナ化: ペリフェラル / セントラル / スキャン / アドバタイジング / ペアリング
- **カタカナ複合語に中黒（・）を使わない**: アドバタイジングパケット（× アドバタイジング・パケット）。英語のスペースを機械的に中黒へ置き換えない。本書は開発現場の慣用・検索性・本文のスキャン性を優先する。ただし、固有名詞の公式表記、外国人名、書名、引用、または語境界を示さないと誤読しやすい場合は例外とする。3語以上で読みにくい場合は、中黒ではなく英語表記に戻すか文を言い換える
- **語尾の長音は付ける**: サーバー / コントローラー / ディスクリプター（×サーバ）
  - 根拠: 内閣告示「外来語の表記」(1991)・現行JIS Z 8301:2019（2019年に長音省略規則を廃止し内閣告示へ一本化）・文化庁(2021)・業界慣行に準拠。「省く」(サーバ)は情報処理学会の学術論文慣行で**本書は不採用**
  - 例外: 定着した短縮形は許容（センサー／センサ）

## コード

- 使用言語: `c` / `python` / `swift` / `bash`
- コメントは日本語可。API名は英語のまま、補足は日本語コメントで
- サンプルコードは出典を明記（仕様書/SDK由来は必須）。本書のコードはMITライセンス

## 図表・数式

- 図番号: `Fig. {章}.{連番}`（本文参照も `Fig. 1.1`）
- サブ図（複数パネル）: `(a) (b) (c)`、各サブ図に短い説明、本文参照は `Fig. 1.1(a)`
- 相互参照は **pandoc-crossref**: `[@sec:chN]` `[@fig:...]` `[@tbl:...]` `[@lst:...]`（直接の数値参照は使わない）
- 数式: インライン `$...$`、ディスプレイ `$$...$$`。変数の意味を直後に説明

## 引用・参考文献

- 本文中は `[番号]`、章末/巻末に番号順でリスト
- 公式仕様書・ドキュメント: アクセス日**不要**
- Wiki・ブログ等の変更されうるリソース: アクセス日**必須**
