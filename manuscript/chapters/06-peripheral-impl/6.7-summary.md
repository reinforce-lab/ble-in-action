## まとめと第7章への橋渡し {#sec:ch6-summary}

<!-- topic: 章のまとめ -->

[@sec:ch6]では、nRF52840上でBLEペリフェラルの主要機能をすべて実装しました。


## 完成したペリフェラルの全体構成

```
完成したペリフェラルの構造

  ┌──────────────────────────────────────────────────────┐
  │  main.c                                               │
  │  ├─ bt_enable() → アドバタイジング開始              │
  │  └─ BT_CONN_CB_DEFINE → 接続/切断ハンドラ           │
  │       ├─ on_connected(): LED ON, タイマー開始        │
  │       └─ on_disconnected(): LED OFF, 再アドバタイズ │
  ├──────────────────────────────────────────────────────┤
  │  ble_service.c（BT_GATT_SERVICE_DEFINE）             │
  │  ├─ PRIMARY_SERVICE（128-bit UUID）                  │
  │  ├─ CHARACTERISTIC: センサー値                       │
  │  │   ├─ Read callback → sensor_val を返す           │
  │  │   ├─ Notify: bt_gatt_notify() で定期送信         │
  │  │   └─ CCCD: sensor_ccc_changed()                  │
  │  └─ CHARACTERISTIC: コントロール                     │
  │      └─ Write callback → LED 制御                   │
  └──────────────────────────────────────────────────────┘
```


## 実装パターンのまとめ表

| 機能 | Kconfig | GATT定義 | コールバック |
|---|---|---|---|
| **Read** | `CONFIG_BT=y` | `BT_GATT_CHRC_READ` + `BT_GATT_PERM_READ` | `read_cb(conn, attr, buf, len, offset)` |
| **Write** | `CONFIG_BT_PERIPHERAL=y` | `BT_GATT_CHRC_WRITE` + `BT_GATT_PERM_WRITE` | `write_cb(conn, attr, buf, len, offset, flags)` |
| **Notify** | 同上 | `BT_GATT_CHRC_NOTIFY` + `BT_GATT_CCC(ccc_cb, ...)` | `ccc_changed(attr, value)` + `bt_gatt_notify()` |
| **接続管理** | `CONFIG_BT_MAX_CONN=1` | ― | `BT_CONN_CB_DEFINE → on_connected/disconnected` |

## 第7章へ：低消費電力設計

[@sec:ch6]で実装したペリフェラルは機能として完成していますが、消費電力は最適化されていません。たとえばアドバタイジング間隔が短すぎると接続を受け付けていない間も電波を頻繁に送信し、電池を浪費します。

[@sec:ch7]では同じペリフェラルをベースに、以下の最適化を行います。

- **スリープモード（System Off / System On）の選択と実装**
- **アドバタイジング間隔の最適化**（接続受付中と待機中の二段階切り替え）
- **接続間隔の交渉**（短い間隔 vs 長い間隔｜スループットと消費電力のトレードオフ）
- **電流測定**：PPK2（Power Profiler Kit 2）を使った実測と、プロファイリングによるボトルネック特定
- **バッテリー駆動の計算**：測定値から動作時間を推算する方法
