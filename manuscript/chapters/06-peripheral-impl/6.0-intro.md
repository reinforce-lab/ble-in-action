# 接続可能アドバタイジング

<!-- topic: 接続可能アドバタイジングへの変更 -->

第5章のHello World では `BT_LE_ADV_NCONN`（接続不可）を使っていました。スマートフォンからの接続を受け付けるには `BT_LE_ADV_CONN`（接続可能）に変更します。

```c
/* 接続可能アドバタイジング */
err = bt_le_adv_start(BT_LE_ADV_CONN,
                      ad, ARRAY_SIZE(ad),
                      sd, ARRAY_SIZE(sd));
```

`BT_LE_ADV_CONN` は `BT_LE_ADV_CONN_FAST_1` などの省略形で、アドバタイジング間隔・タイプ・フィルタポリシーをまとめたパラメータセットです。
