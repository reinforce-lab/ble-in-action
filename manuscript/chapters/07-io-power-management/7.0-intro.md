# BLEと消費電力の基礎 {#sec:ch7}

<!-- topic: 高周波回路の動作電流と平均電流 -->

「BLEは低消費電力」と言われますが、2.4GHz帯の高周波回路そのものの動作電流はクラシックBluetoothと大差ありません。nRF52840のBLE送信時の動作電流は約5mA、受信時は約5mAほどです。

BLEが超低消費電力を実現できる鍵は **稼働時間を最小化すること** です。高周波回路が動いている時間を限りなく短くし、残りの時間は深いスリープ状態に入ることで、**時間平均の電流（平均電流）** を非常に小さく保ちます。

```
時間と電流の関係（概念図）

電流
 ↑
5mA │▌  ▌  ▌  ▌  アドバタイジングパルス（各約1ms）
 │  
 │              
 ↓
0  ───────────────────→ 時間
   ←── 間隔 100ms ──→

平均電流 ≈ 5mA × (1ms / 100ms) = 0.05mA = 50μA
```
