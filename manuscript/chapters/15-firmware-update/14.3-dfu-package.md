<!-- topic: west sign, imgtool, nrfutil pkg generate, .zip構成, バージョン管理 -->


## DFUパッケージとは

iOSアプリが転送するのは生の `.hex` や `.bin` ではなく、**DFUパッケージ** と呼ばれる `.zip` ファイルです。このzipには以下が含まれます。

```
dfu_update.zip
├── app_update.bin     ← 署名済みファームウェアイメージ
└── manifest.json      ← バージョン情報・ファイル名マッピング
```


## west sign でイメージに署名する

nRF Connect SDK のビルド後に `west sign` で署名します。

```bash
# ビルド
west build -b nrf52840dk/nrf52840

# west sign: ビルド成果物に署名してupdate用バイナリを生成
west sign -t imgtool \
    --bin \
    --sbin build/zephyr/zephyr.signed.bin \
    -- --key root-ec-p256.pem \
       --version 1.1.0 \
       --header-size 0x200 \
       --align 4 \
       --slot-size 0x6E000

# 出力: build/zephyr/zephyr.signed.bin (MCUboot headerが付いたイメージ)
```

### バージョン番号の管理

`--version` は `MAJOR.MINOR.REVISION+BUILD` 形式です。MCUbootはバージョンが新しいイメージのみを受け入れます（ダウングレード保護）。

```kconfig
# prj.conf でデフォルトバージョンを設定
CONFIG_MCUBOOT_IMGTOOL_SIGN_VERSION="1.1.0"
```


## nrfutil でパッケージを作成する

`nrfutil` はNordicが提供するCLIツールです。署名済みバイナリからDFUパッケージを生成します。

```bash
# nrfutil のインストール
pip install nrfutil

# DFUパッケージ生成
nrfutil pkg generate \
    --hw-version 52 \
    --sd-req 0x00 \
    --application build/zephyr/zephyr.signed.bin \
    --application-version-string "1.1.0" \
    --key-file root-ec-p256.pem \
    dfu_update_v1.1.0.zip
```

> **注意**: `nrfutil pkg generate` は旧来のSecure DFU形式です。MCUboot + SMP(nRF Connect SDK)の場合、**manifest.json を手動作成**するか、nrfutil device/suit コマンドを使います。本書では手動作成方法を示します。


## manifest.json の手動作成（SMP向け）

```bash
# バイナリをzipにまとめる
mkdir -p dfu_package
cp build/zephyr/zephyr.signed.bin dfu_package/app_update.bin

cat > dfu_package/manifest.json << 'EOF'
{
  "manifest": {
    "application": {
      "bin_file": "app_update.bin",
      "dat_file": ""
    },
    "dfu_version": 0.1,
    "softdevice_required": false
  }
}
EOF

cd dfu_package
zip ../dfu_update_v1.1.0.zip app_update.bin manifest.json
cd ..
```


## バージョン確認

転送後、デバイスが正しいバージョンで動作しているかSMPコマンドで確認できます。

```bash
# mcumgr CLIで確認（nRF Connect SDK付属）
mcumgr --conntype ble --connstring peer_name=BLEInAction_DFU image list

# 出力例:
# Images:
#  image=0 slot=0
#   version: 1.1.0
#   bootable: true
#   flags: confirmed active
#   hash: a3b5c7...
```


## CI/CD での自動化

```yaml
# .github/workflows/dfu-build.yml の例
- name: Build Firmware
  run: west build -b nrf52840dk/nrf52840

- name: Sign Image
  run: |
    west sign -t imgtool --bin \
      --sbin build/zephyr/zephyr.signed.bin \
      -- --key ${{ secrets.DFU_SIGNING_KEY }} \
         --version ${{ github.ref_name }}

- name: Package DFU
  run: |
    python scripts/create_dfu_package.py \
      --binary build/zephyr/zephyr.signed.bin \
      --version ${{ github.ref_name }} \
      --output dfu_${{ github.ref_name }}.zip

- name: Upload Release Asset
  uses: actions/upload-release-asset@v1
  with:
    asset_path: dfu_${{ github.ref_name }}.zip
```

本番では署名鍵をGitHub Secretsに保存し、ビルドサーバー上で署名します。


**まとめ**

- `west sign -t imgtool` でMCUboot headerと署名を付加した `.bin` を生成
- `--version` は`MAJOR.MINOR.REVISION` で指定（ダウングレード防止）
- `manifest.json` + `app_update.bin` を `.zip` にまとめてiOSへ渡す
- CI/CDで自動ビルド → 署名 → パッケージ化を実現できる
