## キャラクタリスティクスの読み出し（Read）

`peripheral.readValue(for:)` を呼ぶと、ATTの Read Request をペリフェラルに送信します。ペリフェラルが応答すると `peripheral(_:didUpdateValueFor:error:)` が呼ばれます。

```swift
// 読み出しを要求
func readTemperature() {
    guard let characteristic = temperatureCharacteristic else { return }
    peripheral?.readValue(for: characteristic)
}

// 読み出し結果を受け取る
func peripheral(
    _ peripheral: CBPeripheral,
    didUpdateValueFor characteristic: CBCharacteristic,
    error: Error?
) {
    if let error = error {
        print("読み出しエラー: \(error)")
        return
    }

    guard let data = characteristic.value else { return }

    switch characteristic.uuid {
    case CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF1"):
        // 2バイトのリトルエンディアン整数として解析（例: 0.01°C 単位）
        let raw = data.withUnsafeBytes { $0.load(as: Int16.self) }
        let temperature = Double(raw) / 100.0
        print("温度: \(temperature)°C")

    default:
        break
    }
}
```

> **注意**: `didUpdateValueFor` は **ReadとNotify双方** で呼ばれます。`characteristic.uuid` で分岐して処理します。


## データのパース

`characteristic.value` は `Data?` 型です。バイト列を適切な型に変換して使います。

### バイト列を数値に変換する

```swift
extension Data {
    // 1バイト符号なし整数
    var uint8: UInt8 {
        return self[0]
    }

    // 2バイトリトルエンディアン符号なし整数
    var uint16LE: UInt16 {
        return UInt16(self[0]) | (UInt16(self[1]) << 8)
    }

    // 4バイトリトルエンディアン浮動小数点
    var float32LE: Float {
        return withUnsafeBytes { $0.load(as: Float.self) }
    }
}

// 使い方
if let value = characteristic.value {
    let temp = Int16(bitPattern: value.uint16LE)
    let celsius = Double(temp) / 100.0
    print("\(celsius)°C")
}
```

### 文字列に変換する

```swift
if let value = characteristic.value,
   let str = String(data: value, encoding: .utf8) {
    print("文字列: \(str)")
}
```


## ATT_MTU の制約（20バイト上限）

ATTプロトコルのデフォルトの Maximum Transfer Unit（ATT_MTU）は **23バイト** です。うち3バイトがATTヘッダに使われるため、1回の操作で送受信できるデータは **最大20バイト** です。

```
ATT_MTU = 23 バイト
  ├── 1 バイト: ATT Opcode
  ├── 2 バイト: Attribute Handle
  └── 20 バイト: Value（実際のデータ）
```

20バイトを超えるデータを1回のReadで取得したい場合は、ペリフェラル側でATT Long Read（ATT Read Blob Request）を実装し、`offset` を使って分割読み出しします。ただし、セントラル側のCore Bluetoothは自動的に `offset` を進めて全データを取得するフラグメンテーション処理をしないため、20バイト以上のデータは分割して送るプロコトルをアプリ層で実装するのが一般的です。

iOS 9以降 / BLE 4.2以降は **MTU Negotiation**（ATT_MTU交換）に対応しており、最大512バイトまでのMTUをネゴシエーションできます。接続後に実際のMTUを確認するには:

```swift
// iOS 17.2+
// peripheral.maximumWriteValueLength(for: .withoutResponse) で確認
let maxWrite = peripheral.maximumWriteValueLength(for: .withoutResponse)
print("最大書き込みサイズ: \(maxWrite) バイト")
```


## キャラクタリスティクスへの書き込み（Write）

`peripheral.writeValue(_:for:type:)` で書き込みます。`type` には2種類あります。

### WriteWithResponse（確認あり）

```swift
func sendCommand(_ command: UInt8) {
    guard let characteristic = commandCharacteristic else { return }

    let data = Data([command])
    peripheral?.writeValue(
        data,
        for: characteristic,
        type: .withResponse  // ATT Write Request
    )
}

// 書き込み完了コールバック
func peripheral(
    _ peripheral: CBPeripheral,
    didWriteValueFor characteristic: CBCharacteristic,
    error: Error?
) {
    if let error = error {
        print("書き込みエラー: \(error)")
        return
    }
    print("書き込み成功: \(characteristic.uuid)")
}
```

`.withResponse` を使うと、ペリフェラルが Write Response を返すまで次の操作を待ちます。不揮発性メモリへの書き込み、設定値の変更など、**完了を必ず確認したい場合** に使います。

### WriteWithoutResponse（確認なし）

```swift
func sendLEDState(_ isOn: Bool) {
    guard let characteristic = ledCharacteristic else { return }

    let data = Data([isOn ? 0x01 : 0x00])
    peripheral?.writeValue(
        data,
        for: characteristic,
        type: .withoutResponse  // ATT Write Command
    )
    // didWriteValueFor は呼ばれない
}
```

`.withoutResponse` はペリフェラルが応答を返さないため、`didWriteValueFor` は呼ばれません。センサーON/OFF、LEDの点滅制御、モーターコマンドなど **結果確認が不要な制御コマンド** に向いています。転送レートも高くなります。

### どちらを選ぶか

| ユースケース | 推奨タイプ |
|---|---|
| 設定値の変更（永続化が必要）| `.withResponse` |
| ファームウェア/設定データの転送 | `.withResponse` |
| LED/モーターなどリアルタイム制御 | `.withoutResponse` |
| 高頻度・大量データ送信 | `.withoutResponse` |


## 複数バイトデータの送信

20バイトを超えるデータを送る場合は、アプリ層で分割して送信します。

```swift
func sendLargeData(_ data: Data) {
    let chunkSize = 20
    var offset = 0

    while offset < data.count {
        let chunk = data.subdata(in: offset..<min(offset + chunkSize, data.count))
        peripheral?.writeValue(chunk, for: characteristic!, type: .withResponse)
        offset += chunkSize
    }
}
```

**注意**: `.withResponse` の場合、前のWrite Responseが返ってくる前に次の `writeValue` を呼ぶと、Core Bluetooth内部のキューに積まれます。順序保証はされますが、エラー処理が複雑になります。大量データ転送にはBLE 4.2以降の **ATT Large Write**（23バイト超のMTUネゴシエーション後）またはカスタムシーケンス番号プロトコルの採用を検討します。


## 読み書きのエラーコード

`error` が渡された場合、`CBATTError.Code` で詳細を確認できます。

```swift
if let error = error as? CBATTError {
    switch error.code {
    case .insufficientAuthentication:
        print("ペアリングが必要です")
    case .insufficientAuthorization:
        print("アクセス権限なし")
    case .readNotPermitted:
        print("このキャラクタリスティクスは読み出し不可")
    case .writeNotPermitted:
        print("このキャラクタリスティクスは書き込み不可")
    case .invalidOffset:
        print("オフセット不正")
    default:
        print("ATTエラー: \(error.code.rawValue)")
    }
}
```


## 実装まとめ: 温度センサーの読み書き

第6章で実装したnRF52840の温度センサーペリフェラルとやり取りするコードをまとめます。

```swift
// UUID定義（ペリフェラル側と一致させる）
let kServiceUUID    = CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF0")
let kTempReadUUID   = CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF1")  // Read
let kThresholdUUID  = CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF3")  // Write

// 温度を読む
func requestTemperature() {
    guard let char = temperatureCharacteristic else { return }
    peripheral?.readValue(for: char)
}

// 閾値を設定する（2バイトリトルエンディアン、0.01°C単位）
func setThreshold(_ celsius: Double) {
    guard let char = thresholdCharacteristic else { return }

    let raw = Int16(celsius * 100)
    var rawLE = raw.littleEndian
    let data = Data(bytes: &rawLE, count: 2)
    peripheral?.writeValue(data, for: char, type: .withResponse)
}

// 読み出し結果を受け取る
func peripheral(_ peripheral: CBPeripheral,
                didUpdateValueFor characteristic: CBCharacteristic,
                error: Error?) {
    guard error == nil, let data = characteristic.value else { return }

    if characteristic.uuid == kTempReadUUID {
        let raw = data.withUnsafeBytes { $0.load(as: Int16.self) }
        let celsius = Double(Int16(littleEndian: raw)) / 100.0
        DispatchQueue.main.async {
            self.onTemperatureUpdate?(celsius)
        }
    }
}
```


**まとめ**

- `readValue(for:)` → `didUpdateValueFor(_:error:)` で非同期読み出し
- `writeValue(_:for:type:)` の `.withResponse` と `.withoutResponse` を用途に応じて使い分ける
- データは最大 **20バイト** が基本制約（MTUネゴシエーションで増やせる）
- 20バイト超のデータはアプリ層で分割送信するか、MTUネゴシエーションを活用
- `didUpdateValueFor` はReadとNotify双方から呼ばれるため、UUIDで分岐する
