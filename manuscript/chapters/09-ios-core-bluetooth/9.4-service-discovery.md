# 9.4 サービスとキャラクタリスティクスの発見

<!-- topic: discoverServices/discoverCharacteristics, CBPeripheralDelegate, GATT探索フロー -->

---

## 接続確立のコールバック

`centralManager.connect(peripheral, options: nil)` を呼び出すと、次のアドバタイズパケットのタイミングで接続処理が始まります。接続が確立すると `centralManager(_:didConnect:)` が呼ばれます。

```swift
func centralManager(_ central: CBCentralManager, didConnect peripheral: CBPeripheral) {
    print("接続確立: \(peripheral.name ?? peripheral.identifier.uuidString)")

    // ① ペリフェラルのデリゲートを自分に設定
    peripheral.delegate = self

    // ② サービスの発見を開始
    let targetServiceUUID = CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF0")
    peripheral.discoverServices([targetServiceUUID])
}
```

**ポイント**: `peripheral.delegate = self` を設定しないと、サービス発見・読み書き・Notifyのコールバックが届きません。接続確立コールバック内で必ず設定します。

接続に失敗した場合は `centralManager(_:didFailToConnect:error:)` が呼ばれます。

```swift
func centralManager(
    _ central: CBCentralManager,
    didFailToConnect peripheral: CBPeripheral,
    error: Error?
) {
    print("接続失敗: \(error?.localizedDescription ?? "不明なエラー")")
    // 再スキャンを試みるなどのエラーハンドリング
    startScanning()
}
```

## サービスの発見

`discoverServices(_:)` の引数に発見したいサービスのUUID配列を渡します。`nil` を渡すとペリフェラルの全サービスを取得しますが、通信時間とバッテリーを余分に消費するため、**UUIDを指定** するのが推奨です。

```swift
peripheral.discoverServices([targetServiceUUID])
```

サービス発見が完了すると `peripheral(_:didDiscoverServices:)` が呼ばれます。

```swift
func peripheral(_ peripheral: CBPeripheral, didDiscoverServices error: Error?) {
    if let error = error {
        print("サービス発見エラー: \(error)")
        return
    }

    guard let services = peripheral.services else { return }

    for service in services {
        print("サービス発見: \(service.uuid)")
        // 目的のサービスのキャラクタリスティクスを発見
        let tempCharUUID   = CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF1")
        let notifyCharUUID = CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF2")
        peripheral.discoverCharacteristics([tempCharUUID, notifyCharUUID], for: service)
    }
}
```

## キャラクタリスティクスの発見

`discoverCharacteristics(_:for:)` で発見したいキャラクタリスティクスのUUID配列を指定します。`nil` を渡すとそのサービスの全キャラクタリスティクスを取得します。

```swift
peripheral.discoverCharacteristics([tempCharUUID, notifyCharUUID], for: service)
```

キャラクタリスティクスの発見が完了すると `peripheral(_:didDiscoverCharacteristicsFor:error:)` が呼ばれます。

```swift
func peripheral(
    _ peripheral: CBPeripheral,
    didDiscoverCharacteristicsFor service: CBService,
    error: Error?
) {
    if let error = error {
        print("キャラクタリスティク発見エラー: \(error)")
        return
    }

    guard let characteristics = service.characteristics else { return }

    for characteristic in characteristics {
        print("キャラクタリスティクス: \(characteristic.uuid) properties: \(characteristic.properties)")

        switch characteristic.uuid {
        case CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF1"):
            // 温度読み出し用: Readキャラクタリスティクスを読む
            peripheral.readValue(for: characteristic)

        case CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF2"):
            // 通知用: Notifyを有効化
            peripheral.setNotifyValue(true, for: characteristic)

        default:
            break
        }
    }
}
```

## キャラクタリスティクスのプロパティ（Properties）

`CBCharacteristic.properties` は `CBCharacteristicProperties` の OptionSet です。ビットフラグの組み合わせで、そのキャラクタリスティクスがどの操作をサポートするかを示します。

| プロパティ | 値 | 意味 |
|---|---|---|
| `.read` | 0x02 | 直接読み出し可能 |
| `.writeWithoutResponse` | 0x04 | 応答なし書き込み可能 |
| `.write` | 0x08 | 応答あり書き込み可能 |
| `.notify` | 0x10 | Notificationをサブスクリプション可能 |
| `.indicate` | 0x20 | Indicationをサブスクリプション可能 |

```swift
// プロパティの確認
if characteristic.properties.contains(.notify) {
    print("このキャラクタリスティクスはNotifyをサポート")
}

if characteristic.properties.contains(.read) {
    peripheral.readValue(for: characteristic)
}
```

通常はペリフェラルの仕様書でプロパティを事前に把握しているため、実行時に確認することは少ないです。ただし、デバッグ中や未知のデバイスと通信する場合には確認が役立ちます。

## 全体の探索フロー

スキャンから通信準備完了までの非同期コールバックの連鎖を整理します。

```
centralManager.scanForPeripherals(withServices:)
  │
  └──→ didDiscoverPeripheral(_:advertisementData:rssi:)
            │
            └──→ centralManager.connect(peripheral:)
                      │
                      └──→ didConnect(peripheral:)
                                │
                                └──→ peripheral.discoverServices(_:)
                                          │
                                          └──→ didDiscoverServices(error:)
                                                    │
                                                    └──→ peripheral.discoverCharacteristics(_:for:)
                                                              │
                                                              └──→ didDiscoverCharacteristicsFor(service:error:)
                                                                        │
                                                                        ├──→ readValue(for:)
                                                                        └──→ setNotifyValue(true, for:)
```

ネストが深くなりがちなため、`Combine` や Swift `async/await`（iOS 14+）を使ってフラットな実装にすることも検討できます。

## キャラクタリスティクスへの参照を保持する

後でRead/Write/Notifyを操作するために、発見したキャラクタリスティクスをプロパティで保持します。

```swift
class BluetoothManager: NSObject, CBCentralManagerDelegate, CBPeripheralDelegate {
    var centralManager: CBCentralManager!
    var peripheral: CBPeripheral?

    // 後で参照するキャラクタリスティクスを保持
    var temperatureCharacteristic: CBCharacteristic?
    var notifyCharacteristic: CBCharacteristic?

    // ...

    func peripheral(
        _ peripheral: CBPeripheral,
        didDiscoverCharacteristicsFor service: CBService,
        error: Error?
    ) {
        for characteristic in service.characteristics ?? [] {
            switch characteristic.uuid {
            case CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF1"):
                temperatureCharacteristic = characteristic
            case CBUUID(string: "12345678-1234-5678-1234-56789ABCDEF2"):
                notifyCharacteristic = characteristic
            default:
                break
            }
        }

        // 準備完了通知
        print("GATT探索完了。通信準備OK")
        setupNotifications()
    }

    private func setupNotifications() {
        guard let notifyChar = notifyCharacteristic else { return }
        peripheral?.setNotifyValue(true, for: notifyChar)
    }
}
```

## 切断検知

ペリフェラルとの接続が切断されると `centralManager(_:didDisconnectPeripheral:error:)` が呼ばれます。

```swift
func centralManager(
    _ central: CBCentralManager,
    didDisconnectPeripheral peripheral: CBPeripheral,
    error: Error?
) {
    if let error = error {
        print("切断（エラー）: \(error)")
    } else {
        print("正常切断")
    }

    // 保持しているキャラクタリスティクスをクリア
    temperatureCharacteristic = nil
    notifyCharacteristic = nil

    // 自動再接続（任意）
    centralManager.connect(peripheral, options: nil)
}
```

`error` が `nil` ならペリフェラル側またはアプリから意図的に切断されたことを示します。`error` が非 `nil` の場合は電波圏外など予期しない切断です。

---

**まとめ**

- 接続確立後は `peripheral.delegate = self` を忘れずに設定する
- GATT探索は非同期コールバックのチェーン: 接続 → サービス → キャラクタリスティクス
- `discoverServices` / `discoverCharacteristics` に **UUIDを指定** して無駄な通信を省く
- 発見したキャラクタリスティクスはインスタンス変数に保持して後続処理で使う
- `CBCharacteristic.properties` で Read/Write/Notify のサポートを確認できる
