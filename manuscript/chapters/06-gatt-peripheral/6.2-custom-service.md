## カスタムサービスの定義 {#sec:custom-service}

<!-- topic: カスタムサービスを作る理由 -->

標準プロファイル（Battery Service・Device Information Serviceなど）はBluetooth SIGが定義しており、16-bit UUIDが割り当てられています。独自アプリケーションには標準にないデータが必要なため、128-bit UUIDを使ったカスタムサービスを定義します。


## 128-bit UUIDの生成

<!-- topic: UUID生成とコード内定義 -->

macOS・Linux では `uuidgen` コマンドで一意なUUIDを生成できます。

```bash
$ uuidgen
12345678-1234-5678-1234-56789ABCDEF0
```

生成したUUIDをZephyrの形式でヘッダファイルに定義します。Zephyrは「リトルエンディアン、128-bitのバイト列」で表現します。

```c
/* ble_service.h */
#ifndef BLE_SERVICE_H
#define BLE_SERVICE_H

#include <zephyr/bluetooth/uuid.h>

/* カスタムサービスUUID: 12345678-1234-5678-1234-56789ABCDEF0 */
#define MY_SERVICE_UUID \
    BT_UUID_DECLARE_128(BT_UUID_128_ENCODE( \
        0x12345678, 0x1234, 0x5678, 0x1234, 0x56789ABCDEF0))

/* センサー値キャラクタリスティックUUID */
#define MY_SENSOR_CHRC_UUID \
    BT_UUID_DECLARE_128(BT_UUID_128_ENCODE( \
        0x12345679, 0x1234, 0x5678, 0x1234, 0x56789ABCDEF0))

/* コントロールキャラクタリスティックUUID */
#define MY_CTRL_CHRC_UUID \
    BT_UUID_DECLARE_128(BT_UUID_128_ENCODE( \
        0x1234567A, 0x1234, 0x5678, 0x1234, 0x56789ABCDEF0))

#endif /* BLE_SERVICE_H */
```

サービスUUIDとキャラクタリスティックUUIDは別のUUIDを使います。上の例では末尾1バイトだけ変えてベースUUIDを流用するパターンです。


## BT_GATT_SERVICE_DEFINE によるサービス定義

<!-- topic: 静的定義マクロ -->

NCSでは `BT_GATT_SERVICE_DEFINE` マクロでGATTサービスを静的に定義します。起動時にZephyrカーネルが自動的にATTデータベースへ登録します。

```c
/* ble_service.c */
#include <zephyr/bluetooth/gatt.h>
#include "ble_service.h"

/* センサー値の値変数 */
static uint16_t sensor_val = 0;

/* コントロール変数 */
static uint8_t ctrl_val = 0;

/* ------------------------------------------------------
 * Read callback（センサー値）
 * ------------------------------------------------------ */
static ssize_t read_sensor(struct bt_conn *conn,
                           const struct bt_gatt_attr *attr,
                           void *buf, uint16_t len, uint16_t offset)
{
    return bt_gatt_attr_read(conn, attr, buf, len, offset,
                             &sensor_val, sizeof(sensor_val));
}

/* ------------------------------------------------------
 * Write callback（コントロール）
 * ------------------------------------------------------ */
static ssize_t write_ctrl(struct bt_conn *conn,
                          const struct bt_gatt_attr *attr,
                          const void *buf, uint16_t len,
                          uint16_t offset, uint8_t flags)
{
    if (len != sizeof(ctrl_val)) {
        return BT_GATT_ERR(BT_ATT_ERR_INVALID_ATTRIBUTE_LEN);
    }
    memcpy(&ctrl_val, buf, sizeof(ctrl_val));
    return len;
}

/* ------------------------------------------------------
 * CCCD 変更コールバック（Notify のON/OFF）
 * ------------------------------------------------------ */
static bool notify_enabled;

static void sensor_ccc_changed(const struct bt_gatt_attr *attr, uint16_t value)
{
    notify_enabled = (value == BT_GATT_CCC_NOTIFY);
}

/* ------------------------------------------------------
 * サービス本体の定義
 * ------------------------------------------------------ */
BT_GATT_SERVICE_DEFINE(my_svc,
    /* プライマリサービス宣言 */
    BT_GATT_PRIMARY_SERVICE(MY_SERVICE_UUID),

    /* センサー値キャラクタリスティック（Read + Notify） */
    BT_GATT_CHARACTERISTIC(MY_SENSOR_CHRC_UUID,
                           BT_GATT_CHRC_READ | BT_GATT_CHRC_NOTIFY,
                           BT_GATT_PERM_READ,
                           read_sensor, NULL, &sensor_val),
    BT_GATT_CCC(sensor_ccc_changed,
                BT_GATT_PERM_READ | BT_GATT_PERM_WRITE),

    /* コントロールキャラクタリスティック（Write） */
    BT_GATT_CHARACTERISTIC(MY_CTRL_CHRC_UUID,
                           BT_GATT_CHRC_WRITE,
                           BT_GATT_PERM_WRITE,
                           NULL, write_ctrl, &ctrl_val),
);
```


## BT_GATT_CHARACTERISTIC の引数

| 引数 | 型 | 意味 |
|---|---|---|
| `uuid` | `bt_uuid *` | キャラクタリスティックのUUID |
| `props` | `uint8_t` | プロパティ（`BT_GATT_CHRC_*`） |
| `perm` | `uint8_t` | パーミッション（`BT_GATT_PERM_*`） |
| `read` | 関数ポインタ | Readコールバック（不要なら `NULL`） |
| `write` | 関数ポインタ | Writeコールバック（不要なら `NULL`） |
| `user_data` | `void *` | コールバックに渡すユーザーデータ |

**プロパティ（`BT_GATT_CHRC_*`）** はGATTのキャラクタリスティック宣言に書かれる値です（クライアントが「このキャラクタリスティックに何ができるか」を確認するためのフィールド）。

**パーミッション（`BT_GATT_PERM_*`）** はATT層のアクセス制御で、実際にReadリクエスト/Writeリクエストを処理するかどうかをカーネルが判断します。

`BT_GATT_CHRC_READ` を設定しても `BT_GATT_PERM_READ` を設定しなければ、Readは許可されません。両方を合わせて設定する必要があります。
