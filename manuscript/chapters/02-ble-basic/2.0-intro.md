# BLE通信の全体像——発見からデータ交換まで {#sec:ch2}

BLE対応の周辺機器を利用するとき、スマートフォンの画面には、機器の発見、接続、値の読み書きといった結果が表示されます。しかし、画面に機器名が現れるまでと、接続後に値が届くまででは、使われるパケットも通信の手順も異なります。

周辺機器は、最初からスマートフォンと通信路を持っているわけではありません。まず、短いアドバタイジングパケットを繰り返し送って存在を知らせます。スマートフォンがそのパケットを受信すると、周辺機器を発見できます。接続後は、二台が決められた時刻と無線チャンネルでパケットを交換します。必要な場合は通信を暗号化し、その通信路の上でGATTの値を読み書きします。

本章では、この流れを通信が進む順番に追います。最初に、パケットを電波で届けるための条件を確認します。続いて、アドバタイジングによる発見、接続、通信路の保護、GATTによるデータ交換へ進みます。

読み進めると、「一覧に機器が現れない」「機器は見つかるのに接続できない」「接続中なのに値を操作できない」「送った値が届かない」といった現象を、通信のどの段階で起きているかに分けられるようになります。
