# BLE通信の全体像——通信フローと登場人物 {#sec:ch2}

[@sec:ch1]では、スマートフォンからmicro:bitへ値を書き込み、LEDを点灯させました。アプリケーションから見ると、目的のキャラクタリスティックを選んで値を書き込むだけです。ファームウェアから見ても、書き込まれた値を受け取るコールバックからLEDを制御するだけでした。

このとき、アプリケーションとファームウェアは、それぞれのSDKを通じて同じGATT基盤を利用していました。アプリケーションはサービスとキャラクタリスティックを探索して値を書き込み、ファームウェアはキャラクタリスティックへの書き込みを受け取ります。どちらの側から見ても、BLEはGATTの値を読み書きする仕組みとして見えていました。

ここからは、この構成を一般的なスマートフォンと周辺機器の通信として捉え、SDKを通じて使っていたGATTの内側へ視点を移します。SDKの向こう側でデータがどのように運ばれているのかを、BLEの仕組みと結び付けて見ていきます。
