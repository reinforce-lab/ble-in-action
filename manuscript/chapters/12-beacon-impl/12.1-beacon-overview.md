## BLEビーコンの仕組み

**BLEビーコン**はペアリング・接続を行わず、アドバタイジングパケットのみを繰り返し送信するデバイスです。スキャン側はパケットを受け取るだけで情報を得られるため、接続オーバーヘッドがなく電池が長持ちします。

```
ビーコン (ペリフェラル)                スキャナ (セントラル)
┌───────────────────────┐             ┌─────────────────────┐
│  ADV_NONCONN_IND 送信   │ ─────────▶ │  受信・解析           │
│  100ms ごとに繰り返し    │             │  接続しない           │
└───────────────────────┘             └─────────────────────┘
```

接続型ビーコン（スキャンレスポンス）も存在しますが、一般的なビーコンは **ADV_NONCONN_IND**（コネクタブルでない広告）を使います。

## iBeacon

**iBeacon** はAppleが2013年に発表したビーコンフォーマットです。アドバタイジングデータのManufacturer Specific Dataフィールド（AD Type: 0xFF）を使います。

```
iBeacon アドバタイズペイロード（合計26バイト）
┌────┬────┬────────────────────────────────────────────┐
│ 02 │ 15 │ UUID (16バイト) │ Major (2B) │ Minor (2B) │ TxPower (1B) │
└────┴────┴────────────────────────────────────────────┘
  ↑    ↑
Apple CompanyID (0x004C) + iBeaconサブタイプ + 長さ
```

| フィールド | サイズ | 用途 |
|---|---|---|
| UUID | 16バイト | アプリ / 組織の識別子 |
| Major | 2バイト | エリア区分（例：フロア番号） |
| Minor | 2バイト | 個体識別（例：棚番号） |
| TxPower | 1バイト | 1m距離での受信電力（dBm）。距離推定に使用 |

### 距離推定

iOSは TxPower と実測RSSI から `CLProximity` を計算します。

$$
d = A \times \left(\frac{\text{RSSI}}{\text{TxPower}}\right)^B + C
$$

ただし環境反射・障害物により精度は±1〜3m程度です。近接（～1m）の検知に向いており、精密な測位には不向きです。

## Eddystone

**Eddystone** はGoogleが2015年に発表したオープンなビーコンフォーマットです。サービスUUID `0xFEAA` を使い、複数のフレームタイプを持ちます。

| フレームタイプ | 用途 |
|---|---|
| Eddystone-UID | 固定IDの送信（iBeaconと同様） |
| Eddystone-URL | URLの送信（Physical Web） |
| Eddystone-TLM | バッテリー電圧・温度などのテレメトリ |
| Eddystone-EID | 暗号化された時変ID（セキュリティ用途） |

```
Eddystone-URL フレーム例
AD Type: 0x16 (Service Data)
Service UUID: 0xFEAA
Frame Type: 0x10 (URL)
TX Power: 0xED (-19 dBm)
URL Scheme: 0x03 (https://)
Encoded URL: "example.com"
```

## iBeacon vs Eddystone

| 項目 | iBeacon | Eddystone |
|---|---|---|
| 策定 | Apple | Google |
| フォーマット | クローズド（Apple規格） | オープン |
| iOS対応 | CLLocationManager（OSレベル） | Core Bluetoothで手動解析 |
| Android対応 | 手動解析 | 各ライブラリでサポート |
| URLビーコン | 非対応 | Eddystone-URLで対応 |
| バックグラウンド検知 | iOS: CLRegion監視で可能 | アプリ起動中のみ |

本書ではiBeaconとEddystone-URLの両方を実装します。

---

**まとめ**

- BLEビーコンはADV_NONCONN_INDで接続なしに情報を送信する
- iBeaconはApple規格。UUID/Major/MinorとTxPowerでエリア・近接判定
- EddystoneはGoogle発のオープンフォーマット。URLも送信できる
- 距離推定はあくまで目安。環境依存が大きい
