## バッテリー駆動の設計と推算 {#sec:battery}

<!-- topic: バッテリーの種類と特性 -->

BLEデバイスでよく使われるバッテリーを比較します。

| バッテリー | 容量 | 電圧 | 特徴 |
|---|---|---|---|
| **CR2032（コイン電池）** | 220mAh | 3.0V | 交換式・小型・入手容易。瞬間大電流には弱い |
| **CR2477（大型コイン電池）** | 900mAh | 3.0V | CR2032の4倍容量。センサーデバイスに |
| **LiPo（充電式）** | 100〜3000mAh | 3.7V（公称） | 充電可能。ただしLiPoの電源回路が必要 |
| **単4形NiMH** | 750〜900mAh | 1.2V | 2本直列で2.4V。nRF52840の動作最低電圧1.7Vをほぼカバー |


## 動作時間の推算

<!-- topic: 計算式と具体例 -->

$$T_{hours} = \frac{C_{battery} \; [mAh]}{I_{avg} \; [mA]}$$

実際のデバイスは複数の電流要因を持つため、加重平均で求めます。

**例：温度センサービーコン**

| フェーズ | 電流 | 時間/周期 | 比率 | 寄与電流 |
|---|---|---|---|---|
| ADVパルス（間隔1000ms） | 5mA | 1ms/1000ms | 0.001 | 5μA |
| センサー読み取り（I2C） | 3mA | 2ms/60000ms | 0.0000333 | 0.1μA |
| CPU処理 | 10mA | 0.5ms/60000ms | 0.0000083 | 0.08μA |
| Notify送信 | 5mA | 2ms/60000ms | 0.0000333 | 0.17μA |
| スリープ | 2μA | 残り | ≈1 | 2μA |
| **合計（平均電流）** | | | | **≈7.35μA** |

$$T = \frac{220 \text{mAh}}{0.00735 \text{mA}} \approx 29,900 \text{時間} \approx 3.4 \text{年}$$

CR2032で約3年動作する計算です。実際には電池の内部抵抗によるドループやCPU起動オーバーヘッドがあるため、推算値の6〜7割程度が実際の動作時間の目安になります。


## バッテリー電圧の監視

<!-- topic: ADCとBattery Serviceによる残量通知 -->

nRF52840のSAADC（Successive Approximation ADC）でバッテリー電圧を測定し、Battery Serviceで残量をスマートフォンに通知できます。

```c
#include <zephyr/drivers/adc.h>
#include <zephyr/bluetooth/services/bas.h>

/* バッテリー電圧から残量（0-100）への変換 */
static uint8_t voltage_to_level(int mv)
{
    /* CR2032: 3000mV = 100%, 2000mV = 0%（近似） */
    if (mv >= 3000) return 100;
    if (mv <= 2000) return 0;
    return (uint8_t)((mv - 2000) * 100 / 1000);
}

/* 定期的にバッテリー電圧を測定してBASを更新 */
void update_battery_level(void)
{
    int mv = read_vdd_mv();   /* ADCで測定（ボードサポート依存） */
    uint8_t level = voltage_to_level(mv);

    bt_bas_set_battery_level(level);
    LOG_INF("Battery: %d mV → %d%%", mv, level);
}
```

Battery Service は `CONFIG_BT_BAS=y` で有効化します。スマートフォンのBLE接続アプリ（nRF Connect for Mobile など）でバッテリーレベルが確認できます。
