# 第9章「Android、Linux、WebからBLEデバイスを使う」執筆方針

## この章の役割

第8章のiOS実装を基準に、同じGATTインターフェースをAndroid、Linux、Webから利用すると何が変わるかを扱います。スキャン、接続、Service／Characteristic探索、Read／Write、Notifyの一般論は繰り返さず、プラットフォーム固有のAPI境界、権限、状態管理、用途を中心に説明します。

Androidは製品アプリ、Linuxは開発中の確認、自動試験、製造検査、Web Bluetoothはインストールを伴わない一時的な設定・診断という位置付けです。Web Bluetoothは独立した実装体系としてではなく、利用環境の制約を受け入れられる場合の選択肢として扱います。

## 第8章との境界

- Value Format、状態、設定、コマンド、イベントの設計は第4章と第8章を正本にする
- 本章では、同じ製品仕様を各APIへ写すときの差だけを説明する
- Web BluetoothではGATT操作の網羅的なコードを再掲しない
- 対応OS、ブラウザー、権限モデルなど変化し得る情報は、出版前に対象バージョンで再確認する

## 既存原稿の扱い

Android／Linux原稿を基礎にします。廃止されたコマンドや古い権限モデルを前提にせず、対象バージョンを明示します。旧Web Bluetooth章からは、ユーザー操作を起点とするデバイス選択、利用環境の制約、設定・診断用途という固有部分だけを移し、接続、探索、Read／Write、Notifyの重複説明は移しません。
