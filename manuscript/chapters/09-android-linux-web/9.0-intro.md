# Android、Linux、WebからBLEデバイスを使う {#sec:ch9}

第8章では、センサー付きライトのGATTインターフェースをiOSから利用しました。スキャンして接続し、ServiceとCharacteristicを探索し、Valueを読み書きする流れは、Android、Linux、Webでも変わりません。変わるのは、BLEの規格ではなく、OSや実行環境がアプリへ見せるAPI、権限、ライフサイクルです。

本章では、同じ製品を三つの環境から利用します。Androidでは、製品アプリを作るときの権限と非同期処理を確認します。Linuxでは、BlueZとBleakを使い、開発、試験、製造でデバイスを操作します。Web Bluetoothは、Webページから一時的に設定や診断を行う選択肢として、採用条件と最小限の実装だけを扱います。

第8章と同じ処理をAPIごとに最初から説明することはしません。各プラットフォームのコードを読んだときに、それがGAP／GATTのどの操作に対応し、製品仕様のどの部分を共通に保つべきかを判断できることを本章の到達点とします。
