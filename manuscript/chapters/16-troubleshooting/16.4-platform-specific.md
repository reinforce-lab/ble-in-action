## iOS: バックグラウンド接続が切れる

```
症状: アプリをバックグラウンドに移すと数秒〜数分で切断される

原因: バックグラウンドBLE実行モードの未設定
```

**Info.plist の設定（必須）**

```xml
<key>UIBackgroundModes</key>
<array>
    <string>bluetooth-central</string>
</array>
```

Xcode では **Signing & Capabilities → + Capability → Background Modes → Uses Bluetooth LE accessories** にチェックを入れることで同じ設定が適用されます。

> **注意**: バックグラウンドでのスキャンは大幅に制限されます（スキャン間隔が長くなる）。バックグラウンドでは既知のペリフェラルへの接続維持は動作しますが、新規デバイスの発見には時間がかかる場合があります。


## iOS: State Restoration で再接続できない

```
症状: アプリがバックグラウンドで終了されると、システム再起動後に
      接続が復元されない
```

State Restoration を使うには、`CBCentralManager` 初期化時に識別子キーを渡す必要があります。

```swift
// ✅ State Restoration 有効化
let centralManager = CBCentralManager(
    delegate: self,
    queue: nil,
    options: [CBCentralManagerOptionRestoreIdentifierKey: "com.example.BLEInAction.central"]
)

// AppDelegate でシステムから呼ばれるメソッドを実装
func centralManager(_ central: CBCentralManager,
                    willRestoreState dict: [String: Any]) {
    if let peripherals = dict[CBCentralManagerRestoredStatePeripheralsKey]
                         as? [CBPeripheral] {
        for peripheral in peripherals {
            peripheral.delegate = self
            // 切断されていれば再接続
            if peripheral.state == .disconnected {
                central.connect(peripheral, options: nil)
            }
        }
    }
}
```

> `CBCentralManagerOptionRestoreIdentifierKey` を指定しないと、アプリ再起動後にシステムからの State Restoration コールバックが来ません。


## Android: GATT_ERROR 133 （接続直後）

```
症状: connectGatt() で接続を試みると、onConnectionStateChange で
      status=133 (GATT_ERROR) が返ってくる

発生タイミング: スキャンのコールバックを受け取った直後に connectGatt() を呼ぶ
```

**対処: 600ms 待機ワークアラウンド**

```kotlin
// ✅ スキャン停止後、少し待ってから接続
private fun connectToDevice(device: BluetoothDevice) {
    bluetoothLeScanner.stopScan(scanCallback)
    
    Handler(Looper.getMainLooper()).postDelayed({
        gatt = device.connectGatt(context, false, gattCallback, TRANSPORT_LE)
    }, 600)  // 600ms 待機
}
```

この遅延はAndroid内部のBLEスタックがスキャンを完全に停止するための時間です。Android 12以降では短縮できることもありますが、600msが最も安全な値です。


## Android: Bond（ペアリング）関連の問題

```
症状: 暗号化が必要なCharacteristicへのアクセス時に
      GATT_INSUFFICIENT_AUTHENTICATION (5) が返ってくる
```

**Bond 状態の監視と処理**

```kotlin
private val bondStateReceiver = object : BroadcastReceiver() {
    override fun onReceive(context: Context, intent: Intent) {
        if (intent.action == BluetoothDevice.ACTION_BOND_STATE_CHANGED) {
            val device = intent.getParcelableExtra<BluetoothDevice>(
                BluetoothDevice.EXTRA_DEVICE)
            val newState = intent.getIntExtra(
                BluetoothDevice.EXTRA_BOND_STATE, BluetoothDevice.ERROR)
            
            when (newState) {
                BluetoothDevice.BOND_BONDED -> {
                    // ペアリング完了: GATTサービスを再発見
                    gatt?.discoverServices()
                }
                BluetoothDevice.BOND_NONE -> {
                    // Bond解除: 接続を切る
                    gatt?.disconnect()
                }
            }
        }
    }
}

// 登録
context.registerReceiver(
    bondStateReceiver,
    IntentFilter(BluetoothDevice.ACTION_BOND_STATE_CHANGED)
)
```

**GATT_INSUFFICIENT_AUTHENTICATION 発生時の対処**

```kotlin
// onCharacteristicRead で status=5 が返ってきた場合
if (status == BluetoothGatt.GATT_INSUFFICIENT_AUTHENTICATION) {
    gatt.device.createBond()  // ペアリングダイアログを表示
}
```


## Web Bluetooth: Safari / iOS Chrome 非対応への対処

```
制限: Web Bluetooth API は以下の環境で動作しない
  - Safari (macOS / iOS): 未実装（2025年時点）
  - iOS の Chrome/Firefox: iOS上ではWKWebViewベースのため不可
  - Firefox (デスクトップ): 未実装

動作環境: Chrome/Edge on Windows, macOS, Android (Chrome 56+)
```

**ユーザーへの代替案提示**

```javascript
async function checkWebBluetoothSupport() {
    if (!navigator.bluetooth) {
        // ユーザーエージェントから推定
        const isIOS = /iPad|iPhone|iPod/.test(navigator.userAgent);
        const isSafari = /^((?!chrome|android).)*safari/i.test(navigator.userAgent);
        
        let message = '';
        if (isIOS) {
            message = 'iOSではWeb Bluetoothは使用できません。App Storeから専用アプリをお試しください。';
        } else if (isSafari) {
            message = 'SafariではWeb Bluetoothは使用できません。Google ChromeまたはMicrosoft Edgeをお試しください。';
        } else {
            message = 'このブラウザはWeb Bluetoothに対応していません。Chrome/Edgeをお試しください。';
        }
        document.getElementById('status').textContent = message;
        return false;
    }
    return true;
}
```

> iOSを主要ターゲットにする場合はネイティブアプリ（CoreBluetooth）か、BLE-Wi-Fiブリッジを検討してください。


**まとめ**

| プラットフォーム | 問題 | 対処 |
|---|---|---|
| iOS | バックグラウンド切断 | `bluetooth-central` + Info.plist |
| iOS | State Restoration 失敗 | `CBCentralManagerOptionRestoreIdentifierKey` |
| Android | GATT_ERROR 133 | スキャン停止後600ms待機 |
| Android | Bond問題 | `ACTION_BOND_STATE_CHANGED` 監視 |
| Web | Safari非対応 | Chrome/Edge case detection + 代替案提示 |
