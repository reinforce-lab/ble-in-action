## BLEスキャンの実装

`BluetoothLeScanner` でスキャンを行います。フィルタには `ScanFilter` を使います。

```kotlin
class BLEManager(private val context: Context) {

    private val bluetoothAdapter: BluetoothAdapter =
        (context.getSystemService(Context.BLUETOOTH_SERVICE) as BluetoothManager).adapter

    private val bleScanner: BluetoothLeScanner
        get() = bluetoothAdapter.bluetoothLeScanner

    private var bluetoothGatt: BluetoothGatt? = null

    // スキャン開始
    fun startScan() {
        val serviceUuid = ParcelUuid.fromString("12345678-1234-5678-1234-56789abcdef0")

        val scanFilter = ScanFilter.Builder()
            .setServiceUuid(serviceUuid)   // サービスUUIDでフィルタ
            .build()

        val scanSettings = ScanSettings.Builder()
            .setScanMode(ScanSettings.SCAN_MODE_LOW_LATENCY)  // 低遅延スキャン（電力大）
            .build()

        bleScanner.startScan(listOf(scanFilter), scanSettings, scanCallback)
        Log.d("BLE", "スキャン開始")
    }

    // スキャン停止
    fun stopScan() {
        bleScanner.stopScan(scanCallback)
    }

    // スキャンコールバック
    private val scanCallback = object : ScanCallback() {
        override fun onScanResult(callbackType: Int, result: ScanResult) {
            val device = result.device
            val rssi   = result.rssi
            Log.d("BLE", "発見: ${device.name ?: "不明"} RSSI=$rssi")

            // 目的のデバイスなら接続
            if (device.name == "BLEInAction_Sensor") {
                stopScan()
                connect(device)
            }
        }

        override fun onScanFailed(errorCode: Int) {
            Log.e("BLE", "スキャン失敗: errorCode=$errorCode")
        }
    }
}
```

### ScanModeの選択

| モード | 消費電力 | スキャン間隔 | 用途 |
|---|---|---|---|
| `SCAN_MODE_LOW_POWER` | 低 | 5秒に1回程度 | バックグラウンド監視 |
| `SCAN_MODE_BALANCED` | 中 | バランス | 一般的な接続前スキャン |
| `SCAN_MODE_LOW_LATENCY` | 高 | 連続 | 素早い接続が必要なとき |


## 接続の実装

`BluetoothDevice.connectGatt()` でGATT接続を開始します。

```kotlin
private fun connect(device: BluetoothDevice) {
    // autoConnect=false: 範囲内にいるときのみ接続試行
    bluetoothGatt = device.connectGatt(context, false, gattCallback)
    Log.d("BLE", "接続試行: ${device.address}")
}
```

接続結果はすべて `BluetoothGattCallback` で受け取ります。

```kotlin
private val gattCallback = object : BluetoothGattCallback() {

    // 接続状態の変化
    override fun onConnectionStateChange(gatt: BluetoothGatt, status: Int, newState: Int) {
        when (newState) {
            BluetoothProfile.STATE_CONNECTED -> {
                Log.d("BLE", "接続成功")
                // メインスレッドでGATT操作を実行
                Handler(Looper.getMainLooper()).post {
                    gatt.discoverServices()
                }
            }
            BluetoothProfile.STATE_DISCONNECTED -> {
                Log.d("BLE", "切断 (status=$status)")
                gatt.close()   // リソース解放必須
                bluetoothGatt = null
            }
        }
    }

    // サービス発見完了
    override fun onServicesDiscovered(gatt: BluetoothGatt, status: Int) {
        if (status != BluetoothGatt.GATT_SUCCESS) {
            Log.e("BLE", "サービス発見失敗: $status")
            return
        }
        val service = gatt.getService(UUID.fromString("12345678-1234-5678-1234-56789abcdef0"))
        if (service != null) {
            Log.d("BLE", "サービス発見: ${service.uuid}")
            readTemperature(gatt, service)
        }
    }

    // キャラクタリスティクス読み出し結果
    override fun onCharacteristicRead(
        gatt: BluetoothGatt,
        characteristic: BluetoothGattCharacteristic,
        value: ByteArray,  // API 33+でvalueが直接渡される
        status: Int
    ) {
        if (status == BluetoothGatt.GATT_SUCCESS) {
            val rawTemp = ByteBuffer.wrap(value).order(ByteOrder.LITTLE_ENDIAN).getShort()
            val celsius = rawTemp / 100.0
            Log.d("BLE", "温度: $celsius°C")
        }
    }

    // キャラクタリスティクス変更通知 (Notify)
    override fun onCharacteristicChanged(
        gatt: BluetoothGatt,
        characteristic: BluetoothGattCharacteristic,
        value: ByteArray
    ) {
        val bb = ByteBuffer.wrap(value).order(ByteOrder.LITTLE_ENDIAN)
        val temp     = bb.getShort() / 100.0
        val humidity = (bb.getShort().toInt() and 0xFFFF) / 100.0
        Log.d("BLE", "Notify受信: temp=$temp humidity=$humidity")
    }
}
```

> **注意**: `onCharacteristicRead` と `onCharacteristicChanged` の旧シグネチャ（`value: ByteArray` がない版）はAndroid API 33で非推奨になりました。両シグネチャをオーバーライドして後方互換を確保するか、ターゲットAPIに合わせて使います。


## GATTスレッドの問題

AndroidのBLEスタックは独自のスレッドで動作するため、`BluetoothGattCallback` のメソッドはメインスレッドではなく **Bluetooth専用スレッド** で呼ばれます。UIを更新する場合はメインスレッドに切り替えます。

```kotlin
// Callbackがメインスレッドで呼ばれないため、UI更新は必ず post する
override fun onCharacteristicChanged(...) {
    Handler(Looper.getMainLooper()).post {
        // UIの更新
        updateUI(temp, humidity)
    }
}
```

Coroutineを使うと `withContext(Dispatchers.Main)` でより宣言的に書けます（11.3節で紹介）。


## 切断と後片付け

`BluetoothGatt` の `close()` は必ず呼ぶ必要があります。呼ばないとシステムリソースがリークし、接続可能なGATTコネクション数の上限（Androidではデバイスあたり数接続）を消費し続けます。

```kotlin
fun disconnect() {
    bluetoothGatt?.let { gatt ->
        gatt.disconnect()   // 切断要求
        // onConnectionStateChange → STATE_DISCONNECTED でclose()を呼ぶのが正しい順序
    }
}

// gattCallback内
override fun onConnectionStateChange(...) {
    when (newState) {
        BluetoothProfile.STATE_DISCONNECTED -> {
            gatt.close()   // ← 必ず呼ぶ
            bluetoothGatt = null
        }
    }
}
```


**まとめ**

- `BluetoothLeScanner` + `ScanFilter` で対象サービスUUIDのデバイスをフィルタスキャン
- `connectGatt()` でGATT接続。結果は `BluetoothGattCallback` で受け取る
- `onConnectionStateChange` → `discoverServices()` → `onServicesDiscovered` のシーケンス
- コールバックはBluetooth専用スレッドで呼ばれる。UIはメインスレッドで更新
- 切断後に `gatt.close()` を必ず呼ぶ（リソースリーク防止）
