## bleakとは

**bleak** (Bluetooth Low Energy platform Agnostic Klient) はPythonのBLEクライアントライブラリです。Windows (WinRT)、macOS (CoreBluetooth)、Linux (BlueZ/D-Bus) に対応しており、同一のコードで動作します。

```bash
pip install bleak
```

本書の実行環境にはRaspberry Pi 4 + Python 3.11以降を想定しています。


## デバイスのスキャン

```python
import asyncio
from bleak import BleakScanner

SERVICE_UUID = "12345678-1234-5678-1234-56789abcdef0"

async def scan():
    """5秒間スキャンしてデバイス一覧を表示する"""
    print("スキャン開始...")
    devices = await BleakScanner.discover(timeout=5.0)
    for d in devices:
        print(f"  {d.address}  {d.name}  RSSI={d.rssi}")

asyncio.run(scan())
```

特定のサービスUUIDを持つデバイスだけを探す場合はコールバックでフィルタします。

```python
async def find_sensor():
    target = None

    def detection_callback(device, advertisement_data):
        nonlocal target
        uuids = advertisement_data.service_uuids
        if SERVICE_UUID.lower() in [u.lower() for u in uuids]:

            target = device

    async with BleakScanner(detection_callback=detection_callback) as scanner:
        await asyncio.sleep(5.0)

    return target
```


## 接続・Read・Write

```python
from bleak import BleakClient
import struct

READ_UUID  = "12345678-1234-5678-1234-56789abcdef1"
WRITE_UUID = "12345678-1234-5678-1234-56789abcdef3"

async def connect_and_read(address: str):
    async with BleakClient(address) as client:
        print(f"接続: {client.is_connected}")

        # サービス一覧
        for service in client.services:
            print(f"サービス: {service.uuid}")
            for char in service.characteristics:
                print(f"  キャラクタリスティクス: {char.uuid}  {char.properties}")

        # Read: バイト列を受け取る
        data = await client.read_gatt_char(READ_UUID)
        raw_temp = struct.unpack_from("<h", data)[0]   # little-endian signed short
        celsius = raw_temp / 100.0
        print(f"温度: {celsius:.2f} °C")

        # Write: 閾値2500 (25.00°C) を little-endian で送る
        threshold = struct.pack("<h", 2500)
        await client.write_gatt_char(WRITE_UUID, threshold, response=True)
        print("閾値書き込み完了")

asyncio.run(connect_and_read("C0:26:DA:XX:XX:XX"))
```

`async with BleakClient(address) as client:` はコンテキストマネージャーを使っています。`with` ブロックを抜けると自動的に切断・後片付けが行われるため、`disconnect()` を明示的に呼ぶ必要はありません。


## Notify の受信

```python
import asyncio
from bleak import BleakClient
import struct

NOTIFY_UUID = "12345678-1234-5678-1234-56789abcdef2"

def notification_handler(characteristic, data: bytearray):
    """Notifyを受け取ったときに呼ばれる"""
    temp, hum = struct.unpack_from("<hH", data)
    print(f"Notify: 温度={temp/100:.2f}°C  湿度={hum/100:.1f}%")

async def subscribe_notify(address: str):
    async with BleakClient(address) as client:
        # Notifyを有効化（CCCD書き込みは内部で自動）
        await client.start_notify(NOTIFY_UUID, notification_handler)
        print("Notify購読開始。60秒間待機...")
        await asyncio.sleep(60.0)
        await client.stop_notify(NOTIFY_UUID)
        print("Notify停止")

asyncio.run(subscribe_notify("C0:26:DA:XX:XX:XX"))
```

bleakでは `start_notify()` を呼ぶだけでCCCDへの書き込みも自動で行われます。AndroidのようにCCCDを手動で書き込む必要はありません。


## 実用スクリプト: 温度ロガー

```python
#!/usr/bin/env python3
"""温度センサーからNotifyを受信しCSVに記録するスクリプト"""

import asyncio
import csv
import struct
import time
from datetime import datetime
from bleak import BleakClient, BleakScanner

SERVICE_UUID = "12345678-1234-5678-1234-56789abcdef0"
NOTIFY_UUID  = "12345678-1234-5678-1234-56789abcdef2"
OUTPUT_CSV   = "temperature_log.csv"

async def find_and_log():
    # デバイスを発見
    print("センサーを検索中...")
    device = await BleakScanner.find_device_by_filter(
        lambda d, ad: SERVICE_UUID.lower() in [u.lower() for u in ad.service_uuids],
        timeout=10.0
    )
    if device is None:
        print("センサーが見つかりません")
        return

    print(f"接続: {device.address}")
    with open(OUTPUT_CSV, "w", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["timestamp", "temperature_c", "humidity_pct"])

        def on_notify(_, data: bytearray):
            temp, hum = struct.unpack_from("<hH", data)
            row = [datetime.now().isoformat(), temp / 100.0, hum / 100.0]
            writer.writerow(row)
            f.flush()
            print(f"{row[0]}  {row[1]:.2f}°C  {row[2]:.1f}%")

        async with BleakClient(device.address) as client:
            await client.start_notify(NOTIFY_UUID, on_notify)
            print("記録中... Ctrl+C で停止")
            try:
                while True:
                    await asyncio.sleep(1)
            except asyncio.CancelledError:
                pass
            finally:
                await client.stop_notify(NOTIFY_UUID)

asyncio.run(find_and_log())
```


## エラーハンドリングと再接続

```python
async def robust_connect(address: str, max_retries=5):
    for attempt in range(max_retries):
        try:
            async with BleakClient(address, timeout=10.0) as client:
                await subscribe_notify_logic(client)
        except Exception as e:
            print(f"試行 {attempt + 1}/{max_retries} 失敗: {e}")
            if attempt < max_retries - 1:
                await asyncio.sleep(2.0)
    print("最大試行回数に達しました")
```


**まとめ**

| 操作 | bleakのメソッド |
|---|---|
| スキャン | `BleakScanner.discover()` |
| 特定デバイス探索 | `BleakScanner.find_device_by_filter()` |
| 接続 | `async with BleakClient(addr) as client:` |
| Read | `client.read_gatt_char(uuid)` |
| Write | `client.write_gatt_char(uuid, data, response=True/False)` |
| Notify購読 | `client.start_notify(uuid, callback)` |
| Notify停止 | `client.stop_notify(uuid)` |

- bleakは単一コードでWindows/macOS/Linuxに対応
- `start_notify()` はCCCD書き込みも内部で行う
- `async with BleakClient` は接続・切断を自動管理
- Raspberry Pi 4 + Python 3.11 + bleak = 手軽なBLEロギング環境
