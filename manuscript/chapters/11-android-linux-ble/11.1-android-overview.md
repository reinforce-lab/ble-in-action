## AndroidのBLE対応の歴史

AndroidのBLE対応は、iOSやWeb Bluetoothに比べて複雑な歴史を持ちます。

| バージョン | 追加された機能 |
|---|---|
| Android 4.3（API 18）| BLE中央役割（セントラル）が初めてサポート |
| Android 5.0（API 21）| `BluetoothLeScanner` API追加（旧`startLeScan()`は非推奨に）|
| Android 6.0（API 23）| 実行時パーミッション必須（`ACCESS_COARSE_LOCATION`）|
| Android 10（API 29）| `ACCESS_FINE_LOCATION` が必須に変更 |
| Android 12（API 31）| `BLUETOOTH_SCAN`/`BLUETOOTH_CONNECT` パーミッション導入（`LOCATION`不要になるケースも）|

Android 12以降はBluetoothパーミッション体系が大幅に変更されました。古いガイドや記事のコードはそのまま動かないことが多いため注意が必要です。


## 主要クラスの概要

AndroidのBLE APIは `android.bluetooth` と `android.bluetooth.le` パッケージに属します。

```
android.bluetooth パッケージ
├── BluetoothManager         BLEサービスのエントリポイント
├── BluetoothAdapter         Bluetooth操作の中心クラス
├── BluetoothDevice          発見・接続済みデバイスの表現
├── BluetoothGatt            GATT接続と操作
├── BluetoothGattCallback    GATT操作の結果を受け取るコールバック
├── BluetoothGattService     GATTサービス
└── BluetoothGattCharacteristic  GATTキャラクタリスティクス

android.bluetooth.le パッケージ
├── BluetoothLeScanner       BLEスキャンの実行
├── ScanCallback             スキャン結果のコールバック
└── ScanFilter / ScanSettings  スキャンの条件・設定
```

Core Bluetooth（iOS）との対応関係:

| iOS (Core Bluetooth) | Android |
|---|---|
| `CBCentralManager` | `BluetoothAdapter` + `BluetoothLeScanner` |
| `CBPeripheral` | `BluetoothDevice` / `BluetoothGatt` |
| `CBService` | `BluetoothGattService` |
| `CBCharacteristic` | `BluetoothGattCharacteristic` |
| Delegate パターン | Callback パターン |


## パーミッションの設定

AndroidManifest.xmlにパーミッションを宣言します（Android 12+対応）。

```xml
<!-- AndroidManifest.xml -->
<manifest ...>
    <!-- Android 12+ (API 31+) -->
    <uses-permission android:name="android.permission.BLUETOOTH_SCAN"
        android:usesPermissionFlags="neverForLocation" />
    <uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />

    <!-- Android 11以前（API 30以下）との後方互換 -->
    <uses-permission android:name="android.permission.BLUETOOTH"
        android:maxSdkVersion="30" />
    <uses-permission android:name="android.permission.BLUETOOTH_ADMIN"
        android:maxSdkVersion="30" />
    <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"
        android:maxSdkVersion="30" />

    <!-- BLE必須デバイス宣言（オプション）-->
    <uses-feature android:name="android.hardware.bluetooth_le" android:required="true" />
    ...
</manifest>
```

実行時に `BluetoothScan` パーミッションを要求します（Android 12+）。

```kotlin
// Activity での実行時パーミッション要求
private val requestPermissionLauncher =
    registerForActivityResult(ActivityResultContracts.RequestMultiplePermissions()) { permissions ->
        val bluetoothScanGranted  = permissions[android.Manifest.permission.BLUETOOTH_SCAN] == true
        val bluetoothConnectGranted = permissions[android.Manifest.permission.BLUETOOTH_CONNECT] == true
        if (bluetoothScanGranted && bluetoothConnectGranted) {
            startBLEScan()
        }
    }

fun requestBLEPermissions() {
    requestPermissionLauncher.launch(
        arrayOf(
            android.Manifest.permission.BLUETOOTH_SCAN,
            android.Manifest.permission.BLUETOOTH_CONNECT
        )
    )
}
```


## BluetoothManagerとBluetoothAdapterの取得

```kotlin
// BluetoothManagerからAdapterを取得
val bluetoothManager = getSystemService(Context.BLUETOOTH_SERVICE) as BluetoothManager
val bluetoothAdapter = bluetoothManager.adapter

// BluetoothAdapterの対応確認
if (bluetoothAdapter == null) {
    // Bluetooth非対応デバイス（まれ）
    return
}

if (!bluetoothAdapter.isEnabled) {
    // Bluetoothがオフ: ユーザーに有効化を促す
    val enableBtIntent = Intent(BluetoothAdapter.ACTION_REQUEST_ENABLE)
    startActivityForResult(enableBtIntent, REQUEST_ENABLE_BT)
}
```


## iOS・Web・Androidの思想の違い

| 観点 | iOS (Core Bluetooth) | Web Bluetooth | Android |
|---|---|---|---|
| 非同期パターン | デリゲート | Promise/await | コールバック（+ Coroutine）|
| 状態管理 | `CBManagerState` | `navigator.bluetooth` | `BluetoothAdapter.STATE_*` |
| パーミッション | Info.plist目的文言 | HTTPS + User Gesture | AndroidManifest + 実行時要求 |
| スキャンUI | デリゲートイベント | OS選択ダイアログ | アプリが独自実装 |

Androidは3者の中で最も柔軟（スキャン結果をアプリが直接受け取り独自UIを作れる）ですが、パーミッション管理が複雑です。


**まとめ**

- Android BLEは API 18〜31にわたる歴史があり、古い情報に注意
- 主要クラスは `BluetoothAdapter`（スキャン制御）、`BluetoothGatt`（GATT操作）、`BluetoothGattCallback`（コールバック受信）
- Android 12以降のパーミッション体系（`BLUETOOTH_SCAN`/`BLUETOOTH_CONNECT`）を使う
- Androidはアプリ側でスキャンUIを自由に実装できる点がiOS/Webと異なる
