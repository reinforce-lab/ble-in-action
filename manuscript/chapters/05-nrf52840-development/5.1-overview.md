## nRF Connect SDK 3.0の構成 {#sec:nrf-overview}

<!-- topic: SDK の構造 -->

**nRF Connect SDK（以下NCS）**はいくつかのコンポーネントで構成されています。

```
nRF Connect SDK 3.0 の構成

┌─────────────────────────────────────────────────────┐
│  アプリケーション（本書で書くコード）                │
├─────────────────────────────────────────────────────┤
│  nRF Connect SDK（Nordicが提供するHAL・ライブラリ）  │
│  ├─ Bluetooth stack（Zephyr Bluetooth + Nordic拡張） │
│  ├─ nRF HAL（nRF52840のペリフェラルドライバ）         │
│  └─ サンプルアプリ群（peripheral, central, etc.）   │
├─────────────────────────────────────────────────────┤
│  Zephyr RTOS（カーネル・デバイスドライバ・Kconfig）  │
├─────────────────────────────────────────────────────┤
│  nRF52840 SoC（Cortex-M4F + BLE Controller + HW）   │
└─────────────────────────────────────────────────────┘
```

**Zephyr RTOS** はLinux Foundationが管理するオープンソースのRTOSで、NCSはこれをベースにしています。スレッド管理・タイマー・割り込み処理・デバイスドライバを提供し、**Kconfig**（`CONFIG_*`フラグ群）でビルドに含めるコンポーネントをメニュー形式で選択できます。

**west** はZephyr/NCSのビルド・フラッシュツールです。`west build`でビルド、`west flash`で書き込み、`west update`で依存関係の更新を行います。


## 開発ツールの全体像

<!-- topic: ツールスタック -->

```
開発ツールの全体図

[PC（macOS / Windows / Linux）]
  │
  ├─ VS Code + nRF Connect for VS Code 拡張機能
  │     → プロジェクト管理・コード編集・ビルド実行・フラッシュ書き込み
  │
  ├─ nRF Connect for Desktop
  │     → Toolchain Manager（SDK・GCCツールチェーン管理）
  │     → Programmer アプリ（HEXファイルの書き込み）
  │     → Serial Terminal（RTT / UARTログ確認）
  │
  └─ J-Link / nRF Command Line Tools
        → nrfjprog（コマンドラインからのフラッシュ書き込み・消去）
        → JLinkExe / JLinkRTTViewer（デバッガ接続・RTTログ）

  USB（J-Link）
  │
[nRF52840 DK（PCA10056）]
  │
  ├─ J-Link OB（オンボードデバッガ）
  ├─ nRF52840 SoC
  ├─ ボタン × 4、LED × 4
  └─ アンテナ（PCBアンテナ一体型）
```

これらすべてを無料で入手・利用できます。nRF52840 DK（開発ボード）は購入が必要ですが（$35〜$40程度）、ソフトウェアはすべてNordicが無償提供しています。
