## 接続とGATT探索 {#sec:connect-gatt}

<!-- topic: gatt.connect, getPrimaryService, getCharacteristic, Promiseチェーン -->


## GATTサーバーへの接続

`BluetoothDevice.gatt.connect()` でGATTサーバーに接続します。接続が成功すると `BluetoothRemoteGATTServer` が返ります。

```javascript
async function connectAndExplore(device) {
    // GATT接続
    const server = await device.gatt.connect();
    console.log('GATT接続: connected =', server.connected);

    // サービス取得（接続後に実行）
    const service = await server.getPrimaryService(
        '12345678-1234-5678-1234-56789abcdef0'
    );
    console.log('サービス取得:', service.uuid);

    // キャラクタリスティクス取得
    const characteristic = await service.getCharacteristic(
        '12345678-1234-5678-1234-56789abcdef1'
    );
    console.log('キャラクタリスティクス取得:', characteristic.uuid);

    return characteristic;
}
```


## BluetoothRemoteGATTServer

`device.gatt` は `BluetoothRemoteGATTServer` オブジェクトです。

| プロパティ/メソッド | 型 | 内容 |
|---|---|---|
| `connected` | `boolean` | 現在の接続状態 |
| `device` | `BluetoothDevice` | 親デバイスへの参照 |
| `connect()` | `Promise<BluetoothRemoteGATTServer>` | GATT接続 |
| `disconnect()` | `void` | GATT切断 |
| `getPrimaryService(uuid)` | `Promise<BluetoothRemoteGATTService>` | サービス1件取得 |
| `getPrimaryServices(uuid?)` | `Promise<BluetoothRemoteGATTService[]>` | サービス複数取得 |


## サービスの取得

### 単一サービスの取得

```javascript
// UUIDを文字列で指定
const service = await server.getPrimaryService(
    '12345678-1234-5678-1234-56789abcdef0'
);

// 16bit SIG標準サービスは数値で指定可能
const batteryService = await server.getPrimaryService(0x180f);
```

### 全サービスの取得

```javascript
// すべてのサービスを取得（requestDevice時にoptionalServicesに宣言が必要）
const services = await server.getPrimaryServices();
for (const service of services) {
    console.log('サービス:', service.uuid);
}
```


## キャラクタリスティクスの取得

`BluetoothRemoteGATTService.getCharacteristic(uuid)` でキャラクタリスティクスを取得します。

```javascript
const service = await server.getPrimaryService('12345678-1234-5678-1234-56789abcdef0');

// 単一取得
const tempCharacteristic = await service.getCharacteristic(
    '12345678-1234-5678-1234-56789abcdef1'
);

// 複数取得
const allCharacteristics = await service.getCharacteristics();
for (const char of allCharacteristics) {
    console.log('キャラクタリスティクス:', char.uuid, 'properties:', char.properties);
}
```

`BluetoothRemoteGATTCharacteristic` の主要プロパティ:

| プロパティ | 内容 |
|---|---|
| `uuid` | キャラクタリスティクスのUUID（文字列）|
| `service` | 親サービスへの参照 |
| `properties` | サポートするプロパティ（read/write/notify等）|
| `value` | 最後に取得した値（`DataView`）|

### properties オブジェクト

```javascript
const char = await service.getCharacteristic('...');
console.log('read:', char.properties.read);             // boolean
console.log('write:', char.properties.write);           // boolean
console.log('notify:', char.properties.notify);         // boolean
console.log('indicate:', char.properties.indicate);     // boolean
console.log('writeWithoutResponse:', char.properties.writeWithoutResponse);
```


## 全体の接続フロー（async/await）

スキャンから通信準備完了までのフローをまとめます。

```javascript
// UUID定数
const SERVICE_UUID  = '12345678-1234-5678-1234-56789abcdef0';
const TEMP_UUID     = '12345678-1234-5678-1234-56789abcdef1';
const NOTIFY_UUID   = '12345678-1234-5678-1234-56789abcdef2';

// 接続と探索をまとめた関数
async function connectSensor() {
    // ① デバイス選択（User Gestureから呼ぶこと）
    const device = await navigator.bluetooth.requestDevice({
        filters: [{ services: [SERVICE_UUID] }]
    });

    // ② GATT接続
    const server = await device.gatt.connect();

    // ③ サービス取得
    const service = await server.getPrimaryService(SERVICE_UUID);

    // ④ キャラクタリスティクス取得
    const [tempChar, notifyChar] = await Promise.all([
        service.getCharacteristic(TEMP_UUID),
        service.getCharacteristic(NOTIFY_UUID)
    ]);

    console.log('接続と探索完了。通信準備OK');
    return { device, service, tempChar, notifyChar };
}
```

`Promise.all()` を使うとキャラクタリスティクスの取得を並列実行でき、待ち時間を短縮できます。


## Promiseチェーン形式（旧式コード）

async/awaitが導入される前のPromiseチェーン形式も見ておきます。同じ処理ですが、ネストが深くなります。

```javascript
// Promiseチェーン形式（参考）
navigator.bluetooth.requestDevice({
    filters: [{ services: [SERVICE_UUID] }]
})
.then(device => device.gatt.connect())
.then(server => server.getPrimaryService(SERVICE_UUID))
.then(service => service.getCharacteristic(TEMP_UUID))
.then(char => {
    console.log('取得完了:', char.uuid);
    return char.readValue();
})
.then(value => {
    console.log('値:', value);
})
.catch(error => {
    console.error('エラー:', error);
});
```

現在はasync/awaitを使ったコードが読みやすく推奨されます。


## GATT切断

`server.disconnect()` で明示的にGATT接続を切断できます。

```javascript
function disconnect(device) {
    if (device.gatt.connected) {
        device.gatt.disconnect();
        console.log('切断しました');
    }
}
```

切断すると `device` で登録した `gattserverdisconnected` イベントが発火します（前節参照）。

```swift
peripheral.delegate = self

```

```javascript
// Web Bluetooth API
const service = await server.getPrimaryService(SERVICE_UUID);
// Promiseが解決したら次の処理 → async/awaitでシーケンシャルに書ける
```

Web Bluetooth APIはPromiseベースなので **async/await でシーケンシャルに書ける** 点がCore Bluetoothのデリゲートパターンより直感的です。ただし、エラーハンドリングが `try/catch` に集約されるため漏れに注意が必要です。


**まとめ**

- `device.gatt.connect()` → `server.getPrimaryService(uuid)` → `service.getCharacteristic(uuid)` の3ステップでGATT探索完了
- `Promise.all()` で複数キャラクタリスティクスの取得を並列化できる
- 接続切断は `server.disconnect()` で明示的に行う
- `gattserverdisconnected` イベントで切断を検知して再接続を実装できる
- async/awaitでシーケンシャルに書ける点がCore Bluetoothのデリゲートパターンより直感的
