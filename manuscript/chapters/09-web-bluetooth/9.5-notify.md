## 9.5 Notifyのサブスクリプション {#sec:web-notify}

<!-- topic: startNotifications, characteristicvaluechanged, stopNotifications -->


## Notifyの有効化

`characteristic.startNotifications()` でCCCDを有効化（Notify購読を開始）します。その後、値が更新されるたびに `characteristicvaluechanged` イベントが発火します。

```javascript
async function subscribeNotifications(notifyChar) {
    // Notifyを有効化
    await notifyChar.startNotifications();

    // 値更新イベントを登録
    notifyChar.addEventListener('characteristicvaluechanged', (event) => {
        const dataView = event.target.value;
        const { tempC, humidity } = parseSensorData(dataView);

        document.getElementById('temp').textContent    = tempC.toFixed(2) + '°C';
        document.getElementById('humidity').textContent = humidity.toFixed(1) + '%RH';
    });

    console.log('Notify購読開始');
}

function parseSensorData(dataView) {
    const rawTemp   = dataView.getInt16(0, true);    // Int16 LE
    const rawHumid  = dataView.getUint16(2, true);   // Uint16 LE
    return {
        tempC:    rawTemp  / 100.0,
        humidity: rawHumid / 100.0
    };
}
```


## イベントリスナーとデータの取得

`characteristicvaluechanged` イベントの `event.target` は `BluetoothRemoteGATTCharacteristic` です。値は `event.target.value` から `DataView` として取得できます。

```javascript
notifyChar.addEventListener('characteristicvaluechanged', (event) => {
    const char     = event.target;             // BluetoothRemoteGATTCharacteristic
    const dataView = event.target.value;       // DataView

    console.log('UUID:', char.uuid);
    console.log('バイト数:', dataView.byteLength);

    // バイト列をダンプ（デバッグ用）
    const bytes = new Uint8Array(dataView.buffer);
    console.log('バイト列:', Array.from(bytes).map(b => '0x' + b.toString(16).padStart(2,'0')).join(' '));
});
```


## Notifyの無効化

`characteristic.stopNotifications()` でNotify購読を停止します。

```javascript
async function unsubscribeNotifications(notifyChar) {
    await notifyChar.stopNotifications();
    notifyChar.removeEventListener('characteristicvaluechanged', handleNotify);
    console.log('Notify購読停止');
}
```

イベントリスナーも `removeEventListener` で明示的に削除します（メモリリーク防止）。


## リアルタイムグラフ: Chart.jsとの組み合わせ

Notifyで受信したセンサーデータをリアルタイムグラフで表示するサンプルです。

```html
<!-- Chart.jsをCDNから読み込む -->
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
<canvas id="tempChart" width="600" height="200"></canvas>

<script>
const MAX_DATA_POINTS = 50;

// Chart.jsグラフの初期化
const ctx = document.getElementById('tempChart').getContext('2d');
const chart = new Chart(ctx, {
    type: 'line',
    data: {
        labels: [],
        datasets: [{
            label: '温度 (°C)',
            data: [],
            borderColor: 'rgb(255, 99, 132)',
            tension: 0.1
        }]
    },
    options: {
        animation: false,          // リアルタイム更新のためアニメーション無効
        scales: { y: { min: 15, max: 40 } }
    }
});

// Notifyハンドラ
function handleTemperatureNotify(event) {
    const dataView = event.target.value;
    const rawTemp  = dataView.getInt16(0, true);
    const tempC    = rawTemp / 100.0;
    const now      = new Date().toLocaleTimeString();

    // データを追加（古いものを削除）
    chart.data.labels.push(now);
    chart.data.datasets[0].data.push(tempC);

    if (chart.data.labels.length > MAX_DATA_POINTS) {
        chart.data.labels.shift();
        chart.data.datasets[0].data.shift();
    }
    chart.update();
}

// Notify購読（接続後に呼ぶ）
async function subscribeWithChart(notifyChar) {
    await notifyChar.startNotifications();
    notifyChar.addEventListener('characteristicvaluechanged', handleTemperatureNotify);
}
</script>
```


## 複数キャラクタリスティクスのNotify

複数のキャラクタリスティクスを同時にサブスクリプションできます。

```javascript
// 複数Notifyを一括で有効化
async function subscribeAll(service) {
    const chars = await service.getCharacteristics();

    const notifiableChars = chars.filter(c => c.properties.notify || c.properties.indicate);

    await Promise.all(
        notifiableChars.map(async char => {
            await char.startNotifications();
            char.addEventListener('characteristicvaluechanged', (event) => {
                handleNotify(event.target.uuid, event.target.value);
            });
            console.log('Notify購読:', char.uuid);
        })
    );
}

function handleNotify(uuid, dataView) {
    switch (uuid) {
    case '12345678-1234-5678-1234-56789abcdef2':   // 温湿度
        const { tempC, humidity } = parseSensorData(dataView);
        updateSensorUI(tempC, humidity);
        break;
    case '12345678-1234-5678-1234-56789abcdef3':   // 加速度センサー
        parseAccelData(dataView);
        break;
    }
}
```


## Readとの使い分け

| 状況 | 推奨方法 |
|---|---|
| 初期値の1回読み出し | `readValue()` |
| センサーデータの継続受信 | Notify（`startNotifications()`）|
| 低頻度（数十秒〜分ごと）データ取得 | ポーリング（`readValue()` を繰り返す）|
| 高頻度（秒以下）リアルタイムデータ | Notify（サーバー側がプッシュ）|

ポーリングよりNotifyの方が電力効率が高く、ペリフェラルが変化したタイミングで通知するため遅延も少ないです。


## Core Bluetoothとの対応関係（Notify）

```swift
// iOS (Core Bluetooth)
peripheral.setNotifyValue(true, for: notifyCharacteristic)

// didUpdateNotificationStateFor でサブスクリプション完了を確認
// didUpdateValueFor で値を受け取る
```

```javascript
// Web Bluetooth API
await notifyChar.startNotifications();   // Promiseで完了を確認
notifyChar.addEventListener('characteristicvaluechanged', handler);
// イベントで値を受け取る
```

処理の流れは同じです。違いはiOSがデリゲートパターン、WebがイベントリスナーパターンとなることとPromiseによる非同期制御です。


**まとめ**

- `startNotifications()` → `characteristicvaluechanged` イベントでリアルタイム受信
- イベントの `event.target.value` が `DataView`。[@sec:ch8]と同じパース方法が使える
- `stopNotifications()` と `removeEventListener` でクリーンアップ
- Chart.jsなどのUIライブラリと組み合わせてリアルタイムグラフが簡単に作れる
- 複数キャラクタリスティクスのNotifyを `Promise.all` で一括有効化できる
