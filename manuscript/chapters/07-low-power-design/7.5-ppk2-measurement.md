## 電流測定とプロファイリング（PPK2）

<!-- topic: Power Profiler Kit 2の概要 -->

**PPK2（Power Profiler Kit 2）** は Nordic が開発した電流測定専用のツールです。nRF Development Kit との接続だけで、マイクロアンペア（μA）オーダーの電流を時系列グラフで可視化できます。

PPK2の特徴：
- 測定範囲：200nA〜1A
- サンプリングレート：最大100kHz
- 電源供給も兼ねる（デバイスを PPK2 から給電して測定）
- 価格：約5,000円（Nordic公式サイト・代理店）

```
接続構成：

  PC（USB）        PPK2                nRF52840 DK
  ────────→ [ PPK2 ] ──VOUT/SENSE──→ [VDD-IN] → SoC
                   └── J-Link OB ────→ デバッグ接続
```

nRF52840 DK の場合、DK上の電源セレクタジャンパを変更してPPK2から電源を供給する構成にします（DKのドキュメント参照）。


## nRF Connect for Desktop PPK アプリ

<!-- topic: PPKアプリの使い方 -->

PPK2の測定は nRF Connect for Desktop の「Power Profiler」アプリで行います。

```
1. PCに PPK2 を USB 接続
2. nRF Connect for Desktop → Power Profiler → Open
3. Device: PPK2 を選択
4. Voltage: 3.0V（CR2032相当）または 3.3V
5. Enable Power Output → ON
6. Start を押すと電流グラフが表示される
```

グラフ上では：
- **アドバタイジングパルス**: 規則正しい鋭い電流ピーク（約5mA × 1ms）
- **接続イベント**: 少し広い形状の電流パルス（TX+RX）
- **スリープ**: 1μA以下のフラットな部分

カーソルで範囲を選択すると、選択区間の**平均電流**が自動計算されます。


## 測定値の例（最適化前後の比較）

<!-- topic: 最適化の効果を測定値で示す -->

第6章の実装から第7章の最適化を適用した場合の測定値例です。

**最適化前（DK デフォルト設定）**:

```
アドバタイジング: 100ms間隔、BT_LE_ADV_CONN
└─ 選択範囲の平均電流: 約 150μA
└─ バッテリー寿命推算（CR2032 220mAh）: 約 61日
```

**最適化後（本章の設定を適用）**:

```
アドバタイジング Fast: 100ms × 30秒 → Slow: 1000ms × 3分 → 停止
接続中: 200ms interval, Latency=9（実質的に2秒に1回のイベント）
CONFIG_PM=y（アイドル時に自動スリープ）
└─ アイドル時の平均電流: 約 5μA
└─ バッテリー寿命推算（CR2032 220mAh）: 約 5年（接続待機のみ）
```


## 電流プロファイルの読み方

<!-- topic: グラフの解釈 -->

PPKグラフで見るべきポイント：

1. **ベースライン電流（スリープ電流）**  
   パルス間のフラットな部分。1〜5μA が理想。20μA以上なら何かが動き続けています（UARTログ・タイマー割り込みなど）。

2. **パルス幅**  
   細いほど良い。BLEアドバタイジングは約1ms。処理が重いとパルスが広くなります。

3. **予期しないパルス**  
   意図しないタイミングで電流スパイクがある場合、不要なタイマーやポーリング処理が動いています。

4. **接続イベントの形状**  
   TX→RX の往復で形状が決まります。Notifyを送るイベントは、空のイベントより少し広い形になります。
