## スリープモード（System On / System Off）

<!-- topic: nRF52840の2つのスリープモード -->

nRF52840には主要な2つのスリープモードがあります。

| モード | Zephyr名 | 電流 | ウェイクアップ | RAM保持 |
|---|---|---|---|---|
| **System On** | `PM_STATE_SUSPEND_TO_IDLE` | 1-100μA | GPIO・タイマー・BLE | ✓ 保持 |
| **System Off** | `PM_STATE_SOFT_OFF` | <1μA | GPIOのみ（DETECT/SENSE配線必要） | ✗ 失う（再起動と同じ） |

**System On**: CPUを止めてRadioとペリフェラル（GPIO割り込み・タイマー）だけが動く状態。BLEアドバタイジングや接続維持が可能。Zephyrの電源管理がアプリコードから透過的に管理してくれるため、通常はこちらを使います。

**System Off**: SoC全体をほぼ完全停止する最深のスリープ。RAM内容は失われ、ウェイクアップ後は再起動します。ボタン押下まで人が来ない設置型デバイスで使います。

## CONFIG_PM による電源管理の有効化

<!-- topic: Kconfig 設定 -->

```kconfig
# prj.conf
CONFIG_PM=y               # Zephyr Power Management 有効化
CONFIG_PM_DEVICE=y        # デバイスドライバの電源管理有効化
CONFIG_UART_CONSOLE=n     # UARTはスリープを妨げるので無効化
CONFIG_RTT_CONSOLE=y
```

`CONFIG_PM=y` を設定すると、Zephyr カーネルがアイドル時に自動的に省電力状態へ遷移します。追加のコードなしにアイドル時の平均電流が大幅に下がります。

## k_sleep によるCPUスリープ

<!-- topic: k_sleep の使い方 -->

メインループで `k_sleep()` を呼ぶと、CPU を sleep させつつタイマーで自動復帰します。BLE スタックとシステムワークキューはバックグラウンドで継続動作します。

```c
int main(void)
{
    /* BLE初期化・アドバタイジング開始 */
    bt_enable(bt_ready);

    /* メインループ：何もしない時はスリープ */
    while (1) {
        /* CPU を止めて省電力状態へ。
           BLEイベント・タイマーで自動復帰。 */
        k_sleep(K_FOREVER);
    }

    return 0;
}
```

`K_FOREVER` は「イベントが来るまで永久に待機」を意味します。BLE の接続イベント・Notify 送信タイマーなどのワークキューイベントで自動的に復帰します。

## GPIOウェイクアップの実装

<!-- topic: ボタン押下でのウェイクアップ -->

System On スリープ中のウェイクアップには GPIO 割り込みを使います。

```c
#include <zephyr/drivers/gpio.h>

static const struct gpio_dt_spec button =
    GPIO_DT_SPEC_GET(DT_ALIAS(sw0), gpios);

static struct gpio_callback button_cb_data;

static void button_pressed(const struct device *dev,
                           struct gpio_callback *cb, uint32_t pins)
{
    LOG_INF("Button pressed, waking up");
    /* ここでワークキューへの処理投入など */
}

static void setup_button_wakeup(void)
{
    gpio_pin_configure_dt(&button, GPIO_INPUT);
    gpio_pin_interrupt_configure_dt(&button, GPIO_INT_EDGE_TO_ACTIVE);
    gpio_init_callback(&button_cb_data, button_pressed,
                       BIT(button.pin));
    gpio_add_callback(button.port, &button_cb_data);
}
```

`GPIO_INT_EDGE_TO_ACTIVE` でボタン押下エッジで割り込みが発生します。スリープ中でも GPIO 割り込みは検出されます。

## System Off モードの実装

<!-- topic: 最深スリープへの遷移 -->

ボタンが一定時間押されなかった場合に System Off へ遷移するパターンです。

```c
#include <zephyr/pm/pm.h>

/* System Off モードへ遷移 */
void enter_system_off(void)
{
    LOG_INF("Entering System Off...");
    LOG_PANIC();  /* ログをフラッシュ */

    /* BLE 停止 */
    bt_le_adv_stop();
    bt_disable();

    /* System Off モードへ.  この関数は戻らない。
       ウェイクアップ時は reset ベクタから再起動。 */
    pm_state_force(0u, &(struct pm_state_info){
        PM_STATE_SOFT_OFF, 0, 0
    });
    k_sleep(K_FOREVER);
}
```

System Off から復帰（GPIO ウェイクアップ）すると nRF52840 は完全再起動します。RAM 内容・接続状態・変数値はすべて失われるため、永続化が必要なデータは事前にフラッシュに書き込みます（`settings_save()` など）。
