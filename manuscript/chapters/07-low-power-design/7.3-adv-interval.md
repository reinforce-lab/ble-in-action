## アドバタイジング間隔の最適化

<!-- topic: アドバタイジング間隔と消費電力 -->

アドバタイジング間隔は消費電力に直接影響します。間隔を10倍にすれば、アドバタイジングによる平均電流はほぼ10分の1になります。

| 間隔 | 平均電流（ADV寄与分のみ） | 発見にかかる時間（目安） |
|---|---|---|
| 20ms（最短） | 約500μA | <0.5秒 |
| 100ms（Fast） | 約100μA | 約0.5秒 |
| 1000ms（Slow） | 約10μA | 約2〜3秒 |
| 10000ms | 約1μA | 約10〜20秒 |

デバイスが「いつ接続されるかわからない」状態で長時間待機する場合、ずっとFast間隔（100ms）にしておくのは無駄が大きいです。


## 二段階アドバタイジング戦略

<!-- topic: Fast→Slow→停止の段階的移行 -->

実践的な実装パターンは「Fast → Slow → 停止（System Off）」の3段階です。

```
時間軸：

0秒                30秒          3分            6分
|-- Fast ADV -------|-- Slow ADV --|-- 停止（System Off or sleep）
  (100ms, 100μA平均)  (1s, 10μA)   (adsv停止 <1μA)
```

接続が来ればその時点でアドバタイジングを停止。来なければ電力を節約しながら待機を続けます。

```c
/* アドバタイジングの状態管理 */
enum adv_state {
    ADV_STATE_IDLE,
    ADV_STATE_FAST,
    ADV_STATE_SLOW,
};
static enum adv_state current_adv_state = ADV_STATE_IDLE;

/* タイマー */
static struct k_work_delayable adv_switch_work;

/* Slow ADVへ切り替えるワーク */
static void switch_to_slow_adv(struct k_work *work)
{
    if (current_adv_state != ADV_STATE_FAST) {
        return;
    }

    LOG_INF("Switch to Slow advertising");
    bt_le_adv_stop();

    /* Slow ADV パラメータ（約1秒間隔） */
    static const struct bt_le_adv_param slow_param = {
        .options      = BT_LE_ADV_OPT_CONNECTABLE,
        .interval_min = BT_GAP_ADV_SLOW_INT_MIN,   /* 1000ms */
        .interval_max = BT_GAP_ADV_SLOW_INT_MAX,   /* 1500ms */
    };

    int err = bt_le_adv_start(&slow_param, ad, ARRAY_SIZE(ad),
                               sd, ARRAY_SIZE(sd));
    if (!err) {
        current_adv_state = ADV_STATE_SLOW;
        /* さらに3分後にアドバタイジング停止 */
        k_work_schedule(&adv_switch_work, K_MINUTES(3));
    }
}

/* ADV停止ワーク */
static void stop_adv(struct k_work *work)
{
    LOG_INF("Advertising timeout, stopping");
    bt_le_adv_stop();
    current_adv_state = ADV_STATE_IDLE;
    /* 必要なら System Off へ遷移 */
}

/* ADV開始（外部から呼ぶ） */
void start_fast_adv(void)
{
    static const struct k_work_handler_t handlers[] = {
        /* 30秒後に Slow ADVへ切り替え */
        [0] = switch_to_slow_adv,
        [1] = stop_adv,
    };

    bt_le_adv_start(BT_LE_ADV_CONN, ad, ARRAY_SIZE(ad),
                    sd, ARRAY_SIZE(sd));
    current_adv_state = ADV_STATE_FAST;

    /* 30秒後に Slow へ切り替え */
    k_work_init_delayable(&adv_switch_work, switch_to_slow_adv);
    k_work_schedule(&adv_switch_work, K_SECONDS(30));
}
```


### NCS 組み込みのタイムアウト機能

<!-- topic: bt_le_adv_param.timeout -->

NCS 2.x 以降では `bt_le_adv_param.timeout` フィールドでアドバタイジングの自動タイムアウトが設定できます。

```c
static const struct bt_le_adv_param adv_param = {
    .options      = BT_LE_ADV_OPT_CONNECTABLE,
    .interval_min = BT_GAP_ADV_FAST_INT_MIN_2,
    .interval_max = BT_GAP_ADV_FAST_INT_MAX_2,
    .timeout      = 2000,   /* 10ms単位: 2000 = 20秒後に自動停止 */
};
```

タイムアウト後は `bt_le_adv_start()` を再度呼ぶまでアドバタイジングが止まります。コールバックは `bt_le_ext_adv_cb.sent` で受け取れます。
