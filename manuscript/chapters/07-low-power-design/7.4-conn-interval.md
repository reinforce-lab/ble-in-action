## 7.4 接続間隔の交渉

<!-- topic: BLE接続パラメータの3要素 -->

BLE接続が確立すると、マスター（スマートフォン）とスレーブ（nRF52840）は定期的に「接続イベント」で通信します。この間隔などを定める3つのパラメータがあります。

| パラメータ | 単位 | 範囲 | 役割 |
|---|---|---|---|
| **Connection Interval** | 1.25ms | 7.5ms〜4000ms | 接続イベントの間隔。短いほど遅延小・電流大 |
| **Slave Latency** | イベント数 | 0〜499 | スレーブは最大この数の接続イベントを無視できる |
| **Supervision Timeout** | 10ms | 100ms〜32000ms | この時間内に応答がなければ切断と判断 |

**Slave Latencyの活用**: Idle時はデータを送らないため、スレーブはN個のイベントをスキップできます。たとえば接続間隔100ms・Latency 9とすると実質的に1秒ごとにしか通信しません。しかしNotyfy送信や緊急応答が必要な場合はすぐ次のイベントに応答できます。

## 接続パラメータの更新要求

<!-- topic: bt_conn_le_param_update の実装 -->

ペリフェラルからセントラル（スマートフォン）に接続パラメータの変更を要求できます。セントラルが承認すれば変更が反映されます。

```c
/* 高スループット用パラメータ（Notify頻度が高い時） */
static const struct bt_le_conn_param high_throughput_param = {
    .interval_min = 8,    /* 10ms (8 × 1.25ms) */
    .interval_max = 12,   /* 15ms */
    .latency      = 0,    /* スキップなし */
    .timeout      = 400,  /* 4秒（400 × 10ms） */
};

/* 低消費電力用パラメータ（アイドル時・待機時） */
static const struct bt_le_conn_param low_power_param = {
    .interval_min = 80,   /* 100ms */
    .interval_max = 160,  /* 200ms */
    .latency      = 9,    /* 9イベントスキップ可（実質1〜2秒に1回） */
    .timeout      = 400,  /* 4秒 */
};

/* 接続直後に低消費電力パラメータを要求 */
static void on_connected(struct bt_conn *conn, uint8_t err)
{
    /* ... 省略 ... */

    int ret = bt_conn_le_param_update(conn, &low_power_param);
    if (ret) {
        LOG_WRN("Param update request failed (err %d)", ret);
    }
}

/* Notify送信前に高スループットパラメータを要求 */
void request_high_throughput(struct bt_conn *conn)
{
    bt_conn_le_param_update(conn, &high_throughput_param);
}
```

## iOSの制限について

<!-- topic: Appleガイドラインの制約 -->

iOSはBluetooth Accessory Guidelinesにより接続パラメータに制約を課しています。

| 制限 | 値 |
|---|---|
| 最小 Connection Interval | 15ms |
| 最大 Slave Latency | 30（または `supervision_timeout / (connection_interval × 2 + 1)` 内） |
| Supervision Timeout の最小 | Max(2秒, `(1 + latency) × interval × 3`) |

15ms 未満の間隔をリクエストしても iOS が拒否します。iOS が返す実際のパラメータは `on_le_param_updated` コールバックで確認できます。

```c
static struct bt_conn_cb conn_callbacks = {
    .connected        = on_connected,
    .disconnected     = on_disconnected,
    .le_param_updated = on_le_param_updated,
};

static void on_le_param_updated(struct bt_conn *conn,
                                uint16_t interval,
                                uint16_t latency,
                                uint16_t timeout)
{
    LOG_INF("Params updated - interval: %u (%.1f ms), "
            "latency: %u, timeout: %u",
            interval, interval * 1.25f, latency, timeout);
}
```
