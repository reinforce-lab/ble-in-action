# 第7章: 低消費電力設計

## 章の概要

nRF52840のBLEペリフェラルで消費電力を最適化する。第6章のペリフェラル実装をベースに、スリープモード制御・アドバタイジング間隔の最適化・接続間隔の交渉を実施し、PPK2による実測でその効果を確認する。コイン電池で年単位動作するデバイス設計の考え方を体得する。

**想定ページ数**: 25-30ページ  
**前提章**: 第6章（ペリフェラル実装）

---

## 節構成

### 7.1 BLEと消費電力の基礎（3-4ページ）

- 2.4GHz高周波回路の動作電流と平均電流の違い
- 高周波回路の稼働時間を最小化することがBLEの省電力の核心
- アドバタイジング・スキャン・接続それぞれの消費電流プロファイル
- 電流積分（平均電流）とバッテリー容量から動作時間を計算する方法

### 7.2 スリープモード（System On / System Off）（5-6ページ）

- nRF52840の2つのスリープモードとウェイクアップ経路
- Zephyrの `k_sleep()` / `pm_device` API による低消費電力遷移
- `CONFIG_PM=y` / `CONFIG_PM_DEVICE=y` の設定
- GPIOウェイクアップ（ボタン押下での復帰）
- System Off モードのRAM保持と再起動時の注意点

### 7.3 アドバタイジング間隔の最適化（4-5ページ）

- 接続可能アドバタイジングの消費電流（間隔別）
- 二段階アドバタイジング戦略：Fast（100ms）→ Slow（1sec）→ 停止
- `bt_le_adv_stop()` と `bt_le_adv_start()` の組み合わせ
- タイムアウト付きアドバタイジングの実装

### 7.4 接続間隔の交渉（4-5ページ）

- Connection Interval・Latency・Supervision Timeoutのトレードオフ
- ペリフェラルからの接続パラメータ更新要求：`bt_conn_le_param_update()`
- iOSの制限（最小15ms、Appleガイドライン）
- 高スループット時と待機時の間隔切り替えパターン

### 7.5 電流測定とプロファイリング（5-6ページ）

- PPK2（Power Profiler Kit 2）の使い方
- nRF Connect for Desktop PPK アプリ
- アドバタイジングパルス・接続イベントを実際に測定する
- 最適化前後の電流プロファイル比較

### 7.6 バッテリー駆動の設計と推算（3-4ページ）

- コイン電池（CR2032: 220mAh）と LiPo の特性比較
- 平均電流から動作時間を推算する式
- 改善例：100ms ADV間隔 vs 1sec ADV間隔の動作時間比較
- 実機でのバッテリー電圧監視（ADCとBattery Service）

### 7.7 まとめと第8章への橋渡し（1-2ページ）

- 低消費電力設計のチェックリスト
- 第8章予告：外部センサーチップとnRF52840の連携（SPI/I2C・LTE統合）
