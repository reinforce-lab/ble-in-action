## ビーコンのユースケース

ビーコンは「接続不要で位置情報コンテキストを発信する」という特性から、以下のユースケースに適しています。

| ユースケース | 概要 |
|---|---|
| 店舗・施設内案内 | エリアに入るとiPhoneに関連情報をプッシュ |
| 展示物への追加情報 | 展示ケース近くに来たらURLをポップアップ |
| 在庫管理 | 棚にビーコン設置 → スキャナで位置確認 |
| 資産追跡 | Major/Minorで個体識別したデバイスを追跡 |
| 入退室管理 | CLBeaconRegion の in/out でゲート制御 |
| テレメトリ収集 | 独自のAdvertising Dataでセンサーデータを定期送信 |


## ビーコン vs 接続型BLE の選択

```
どちらを選ぶべき？
┌───────────────────────────────────────────────────────────────┐
│  一方向・定期送信でよい？                                       │
│  ├─ Yes → ビーコン (ADV_NONCONN)                               │
│  │         電力消費: 最小 / 実装: シンプル                       │
│  └─ No → 接続型BLE                                             │
│           データを読み書き・設定変更が必要な場合                  │
│                                                               │
│  距離精度 < 1m が必要？                                         │
│  ├─ Yes → UWB (Ultra Wide Band) を検討                         │
│  └─ No → ビーコン近接判定 (immediate/near/far) で十分な場合多い  │
└───────────────────────────────────────────────────────────────┘
```


## 精度向上の手法

RSSIによる距離推定は環境依存が大きいため、精度向上には複数の手法を組み合わせます。

1. **複数ビーコンの三角測位**: 3点以上の距離から交点を計算
2. **カルマンフィルタ**: RSSSIのノイズを時系列フィルタで平滑化
3. **TxPowerの事前較正**: 設置環境ごとに1m測定値を記録
4. **フロアマップとのフュージョン**: 壁・障害物の物理モデルと組み合わせ


## 第10章まとめ

本章では以下を学びました。

1. **ビーコンの仕組み**: ADV_NONCONN_INDとiBeacon形式
2. **nRF52840ビーコン実装**: `BT_DATA_MANUFACTURER_DATA` によるiBeaconフォーマット、`BT_LE_ADV_NCONN` でのノンコネクタブルアドバタイズ
3. **iOSでの受信**: `CLLocationManager` によるモニタリング（バックグラウンド可）とレンジング（CLProximity）
4. **Androidでの受信**: `ScanRecord.getManufacturerSpecificData(0x004C)` での手動パース、距離推定式
