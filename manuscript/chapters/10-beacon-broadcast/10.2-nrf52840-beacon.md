## iBeacon のアドバタイズデータ

ZephyrでiBeaconを実装するには、`BT_DATA_MANUFACTURER_DATA` を使って Appleフォーマットのバイト列を手動で構築します。

```c
#include <zephyr/kernel.h>
#include <zephyr/bluetooth/bluetooth.h>
#include <zephyr/bluetooth/hci.h>

/* iBeacon UUID: 本書オリジナル */
#define IBEACON_UUID \
    0x01, 0x23, 0x45, 0x67, \
    0x89, 0xAB, 0xCD, 0xEF, \
    0xFE, 0xDC, 0xBA, 0x98, \
    0x76, 0x54, 0x32, 0x10

#define IBEACON_MAJOR    0x00, 0x01    /* Major = 1 */
#define IBEACON_MINOR    0x00, 0x01    /* Minor = 1 */
#define IBEACON_RSSI     0xC5          /* TxPower = -59 dBm @ 1m */

/*
 * iBeacon Manufacturer Specific Data (26バイト)
 *   [0-1]   Apple Company ID: 0x004C (little-endian → 0x4C, 0x00)
 *   [2]     iBeacon subtype: 0x02
 *   [3]     Length: 0x15 (21)
 *   [4-19]  Proximity UUID (16バイト)
 *   [20-21] Major
 *   [22-23] Minor
 *   [24]    TX Power
 */
static const uint8_t ibeacon_data[] = {
    0x4C, 0x00,                       /* Apple Inc. CompanyID */
    0x02, 0x15,                       /* iBeacon subtype, length */
    IBEACON_UUID,                     /* Proximity UUID */
    IBEACON_MAJOR,                    /* Major */
    IBEACON_MINOR,                    /* Minor */
    IBEACON_RSSI                      /* TX Power */
};

static const struct bt_data ad[] = {
    BT_DATA_BYTES(BT_DATA_FLAGS, BT_LE_AD_NO_BREDR),
    BT_DATA(BT_DATA_MANUFACTURER_DATA, ibeacon_data, sizeof(ibeacon_data)),
};
```


## アドバタイズパラメータの設定

iBeaconは接続不可（NONCONN）でアドバタイズします。低電力運用のために間隔を長めに設定します。

```c
/* アドバタイズパラメータ */
static const struct bt_le_adv_param adv_param = {
    .id          = BT_ID_DEFAULT,
    .sid         = 0,
    .secondary_max_skip = 0,
    /* ノンコネクタブル・スキャン不可 */
    .options     = BT_LE_ADV_OPT_USE_IDENTITY,
    /* アドバタイズ間隔: 500ms (単位: 0.625ms → 800) */
    .interval_min = BT_GAP_ADV_SLOW_INT_MIN,   /* = 1000ms min */
    .interval_max = BT_GAP_ADV_SLOW_INT_MAX,   /* = 1280ms max */
    .peer = NULL,
};
```

標準マクロ `BT_LE_ADV_NCONN` を使うとよりシンプルです。

```c
/* main.c */
int main(void)
{
    int err;

    err = bt_enable(NULL);
    if (err) {
        printk("Bluetooth初期化失敗: %d\n", err);
        return err;
    }

    /* ノンコネクタブルで開始 */
    err = bt_le_adv_start(BT_LE_ADV_NCONN, ad, ARRAY_SIZE(ad), NULL, 0);
    if (err) {
        printk("アドバタイズ開始失敗: %d\n", err);
        return err;
    }

    printk("iBeacon アドバタイズ開始\n");

    /* ビーコンは永続動作: メインループは不要 */
    while (1) {
        k_sleep(K_SECONDS(10));
        /* 定期的にTX電力を調整する場合はここで bt_le_set_tx_power() */
    }
}
```


## TX電力の調整

TxPower値は 1m 距離での受信RSSIを事前測定して設定します。nRF52840のデフォルトTX電力は 0 dBm です。

```c
/* TX電力を +4dBm に設定（最大出力） */
bt_le_set_tx_power(4, 0, 0);

/* iBeacon TxPowerフィールドに入れる値（dBm）も合わせて更新 */
/* 通常は事前測定して定数として埋め込む */
```

1mで計測した実RSSIの典型値は -59 dBm（環境により変動）です。`0xC5` = (uint8_t)(-59) = 0xC5 で表現します。

**まとめ**

- iBeaconは `BT_DATA_MANUFACTURER_DATA` で 26バイトのAppleフォーマットを構築する
- `bt_le_adv_start(BT_LE_ADV_NCONN, ...)` でノンコネクタブルアドバタイズを開始
- TxPowerは 1m 実測RSSIを使う（-59 dBm が典型値）
