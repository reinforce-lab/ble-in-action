## iBeaconデータの解析

AndroidにはiBeaconのOSレベルサポートはありません。`ScanRecord` から Manufacturer Specific Data を取り出して手動でパースします。

```kotlin
import android.bluetooth.le.ScanCallback
import android.bluetooth.le.ScanResult
import java.nio.ByteBuffer
import java.nio.ByteOrder
import java.util.UUID

data class IBeacon(
    val uuid: UUID,
    val major: Int,
    val minor: Int,
    val txPower: Int,
    val rssi: Int
)

fun parseIBeacon(result: ScanResult): IBeacon? {
    val scanRecord = result.scanRecord ?: return null

    // Manufacturer Specific Data を取得 (Apple CompanyID = 0x004C)
    val appleCompanyId = 0x004C
    val mfData = scanRecord.getManufacturerSpecificData(appleCompanyId) ?: return null

    // iBeaconのバイト構造確認
    // [0]=0x02 (subtype), [1]=0x15 (length=21), [2..17]=UUID, [18-19]=Major, [20-21]=Minor, [22]=TxPower
    if (mfData.size < 23) return null
    if (mfData[0] != 0x02.toByte() || mfData[1] != 0x15.toByte()) return null

    val bb = ByteBuffer.wrap(mfData, 2, 21)

    // UUID (big-endian)
    val mostSig  = bb.getLong()
    val leastSig = bb.getLong()
    val uuid     = UUID(mostSig, leastSig)

    val major   = ((mfData[18].toInt() and 0xFF) shl 8) or (mfData[19].toInt() and 0xFF)
    val minor   = ((mfData[20].toInt() and 0xFF) shl 8) or (mfData[21].toInt() and 0xFF)
    val txPower = mfData[22].toInt()   // signed byte

    return IBeacon(uuid, major, minor, txPower, result.rssi)
}
```


## スキャンコールバックでのビーコン検出

```kotlin
private val targetUuid = UUID.fromString("01234567-89ab-cdef-fedc-ba9876543210")

private val beaconScanCallback = object : ScanCallback() {
    override fun onScanResult(callbackType: Int, result: ScanResult) {
        val beacon = parseIBeacon(result) ?: return
        if (beacon.uuid != targetUuid) return

        val distance = estimateDistance(beacon.txPower, beacon.rssi)
        Log.d("Beacon", "UUID=${beacon.uuid} Major=${beacon.major} Minor=${beacon.minor}")
        Log.d("Beacon", "RSSI=${beacon.rssi} TxPower=${beacon.txPower} 距離≈${"%.1f".format(distance)}m")
    }
}

// 距離推定（Log-distance path loss モデル）
fun estimateDistance(txPower: Int, rssi: Int): Double {
    if (rssi == 0) return -1.0
    val ratio = rssi.toDouble() / txPower
    return if (ratio < 1.0) {
        Math.pow(ratio, 10.0)
    } else {
        0.89976 * Math.pow(ratio, 7.7095) + 0.111
    }
}
```


## スキャンの開始

iBeaconはサービスUUIDをアドバタイズしないため、`ScanFilter` でUUIDフィルタができません。 **フィルタなし**でスキャンし、コールバック内でApple CompanyIDを確認します。

```kotlin
fun startBeaconScan() {
    val settings = ScanSettings.Builder()
        .setScanMode(ScanSettings.SCAN_MODE_LOW_LATENCY)
        .build()

    // フィルタなし（iBeaconはサービスUUIDを含まないため）
    bleScanner.startScan(null, settings, beaconScanCallback)
    Log.d("Beacon", "ビーコンスキャン開始")
}
```

> **注意**: フィルタなしスキャンは全デバイスのパケットを処理するため電力消費が大きくなります。距離が近くなった場合のみレンジングに切り替えるなど、用途に応じてスキャンモードを調整してください。


## AltBeacon ライブラリ

手動実装の代わりに **AltBeacon** ライブラリ（`org.altbeacon:android-beacon-library`）を使うとiBeaconをシンプルに扱えます。

```kotlin
// build.gradle.kts
dependencies {
    implementation("org.altbeacon:android-beacon-library:2.20.3")
}
```

```kotlin
class MyApplication : Application(), BeaconConsumer {

    private val beaconManager by lazy { BeaconManager.getInstanceForApplication(this) }

    override fun onCreate() {
        super.onCreate()
        // iBeacon パーサーを登録
        BeaconManager.getInstanceForApplication(this).beaconParsers.add(
            BeaconParser().setBeaconLayout("m:2-3=0215,i:4-19,i:20-21,i:22-23,p:24-24,d:25-25")
        )
    }

    override fun onBeaconServiceConnect() {
        beaconManager.addRangeNotifier { beacons, region ->
            for (beacon in beacons) {
                Log.d("AltBeacon", "Id1: ${beacon.id1} dist: ${"%.1f".format(beacon.distance)}")
            }
        }
        beaconManager.startRangingBeaconsInRegion(
            Region("myRegion", Identifier.fromUuid(UUID.fromString("01234567-89ab-cdef-fedc-ba9876543210")), null, null)
        )
    }
}
```


**まとめ**

- Androidには iBeacon のOS向けAPIがないため `ScanRecord.getManufacturerSpecificData(0x004C)` で手動パース
- iBeaconはサービスUUIDを持たないためスキャンフィルタなしで全スキャン
- 距離推定はLog-distanceモデルで計算（精度±1〜2m）
- AltBeaconライブラリを使うとiBeaconの処理を簡略化できる
