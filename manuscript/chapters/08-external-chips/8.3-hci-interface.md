## HCIインターフェース（nRF52840をBLEコントローラとして使う）

<!-- topic: HCI の仕組みとユースケース -->

HCI（Host Controller Interface）は Bluetooth 仕様書で定義されたコマンド/イベントプロトコルで、**BLE Host スタック（ソフトウェア）** と **BLE Controller（ハードウェア近くのロジック）** を物理的に分離します。

```
HCI を使う構成

  メインMCU / Linux PC / Raspberry Pi
  ┌─────────────────────────────────┐
  │  Application                   │
  │  BLE Host Stack（Zephyr/BlueZ）│
  │  HCI ドライバ（UART）           │
  └────────────────┬────────────────┘
                   │ UART（HCI パケット）
  ┌────────────────▼────────────────┐
  │  nRF52840 （hci_uart ファーム） │
  │  BLE Controller                 │
  │  Radio（2.4GHz）               │
  └─────────────────────────────────┘
```

**この構成が有効なケース**:
- 既存の Linux ボード（Raspberry Pi 等）に BLE を追加したい
- 処理能力の高いメイン CPU（STM32H7 等）で Bluetooth Host スタックを管理したい
- Linuxの `BlueZ` スタックと nRF52840 Controller の組み合わせ

## nRF52840 の hci_uart サンプルのセットアップ

<!-- topic: hci_uart サンプルのビルドとフラッシュ -->

NCS には `hci_uart` サンプルが付属しています。

```bash
# hci_uart サンプルをビルド
$ cd $NCS_PATH/nrf/samples/bluetooth/hci_uart
$ west build -b nrf52840dk_nrf52840
$ west flash
```

`hci_uart` ファームウェアを書き込んだ nRF52840 は HCI UART モードで起動します。DKのデフォルトでは UART0（ピン P0.06/P0.08, ボーレート 1Mbps、HWFC有効）が HCI インターフェースになります。

ボーレートと HWFC（ハードウェアフロー制御）の設定は `prj.conf` で変更可能です。

```kconfig
CONFIG_BT_HCI_UART_BAUDRATE=1000000
CONFIG_BT_HCI_UART_FLOW_CONTROL=y
```

## Raspberry Pi（BlueZ）との接続例

<!-- topic: Linux BlueZ + nRF52840 構成 -->

Raspberry Pi に nRF52840 DK を UART 接続して BlueZ から BLE を使う場合の設定例です。

```bash
# 1. USBシリアルで接続した nRF52840 を HCI デバイスとして認識させる
$ sudo btattach -B /dev/ttyACM0 -S 1000000 -P h4

# 2. hci1（nRF52840）が現れる
$ hciconfig
hci0: [Raspberry Pi 内蔵]
hci1: [nRF52840] Type: Primary  Bus: UART

# 3. hci1 で BLE スキャン
$ hcitool -i hci1 lescan
```

BlueZ の `bluetoothctl` や Python の `bluepy`、`bleak` ライブラリからも `hci1` を指定して利用できます。

## トラブルシューティング

<!-- topic: よくある問題と対処 -->

**問題1: デバイスが応答しない**  
→ ボーレートが一致しているか確認 (`CONFIG_BT_HCI_UART_BAUDRATE`)  
→ TX/RX が逆になっていないか確認（nRF の TX は相手の RX へ）

**問題2: データ化けが多い**  
→ `CONFIG_BT_HCI_UART_FLOW_CONTROL=y` を確認。RTS/CTS ラインを結線する。

**問題3: btattach が失敗する**  
→ `hci_uart` ファームウェアが Flash に書き込まれているか確認。  
→ USB-UART アダプタのドライバが認識されているか確認 (`ls /dev/ttyACM*`)。
