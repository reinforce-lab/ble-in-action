## 電源シーケンスと設計上の落とし穴

<!-- topic: 電圧レベルの不一致 -->

外部チップとの連携でもっとも多いトラブルが **電圧レベルの不一致** です。nRF52840 の GPIO は 3.3V 動作ですが、センサーによっては 1.8V 動作のものがあります。

| 組み合わせ | 問題 | 対処 |
|---|---|---|
| nRF52840（3.3V）← 1.8V センサー | 信号が認識される（スペック外） | レベル変換IC（例：TXS0102）を挟む |
| nRF52840（3.3V）→ 1.8V センサー | センサーを破損する可能性あり | **必ずレベル変換する** |
| 同一電圧どうし | 問題なし | ― |

nRF52840 DK は 3.3V 動作、多くのセンサーはデータシートに I/O 電圧仕様（VDD IO）が記載されています。回路設計前に必ずセンサーのデータシートで VDD IO を確認します。


## I2C プルアップ抵抗の選び方

<!-- topic: プルアップ抵抗の適切な値 -->

I2C の SDA・SCL はオープンドレインのため、プルアップ抵抗が必要です。

```
プルアップ抵抗の目安（VDD=3.3V）

  ┌────────────────────────────────────┐
  │  Standard Mode（100kHz）: 4.7kΩ   │
  │  Fast Mode（400kHz）:   2.2〜4.7kΩ│
  │  Fast-plus（1MHz）:     1.0kΩ     │
  └────────────────────────────────────┘
```

プルアップが弱すぎる（値が大きすぎる）と立ち上がりが鈍くなり通信エラーになります。強すぎる（値が小さすぎる）と消費電力が増え、センサーのドレイン電流仕様を超える可能性があります。

なお、nRF52840 の GPIO には内部プルアップもあります（通常 11〜16kΩ）が、I2C では外部プルアップを使うのが推奨です。


## 電源投入シーケンス

<!-- topic: 起動順序の重要性 -->

複数チップが混在する設計では電源投入順序（パワーシーケンス）が重要です。特にセンサーのリセット方法によっては起動時に誤動作することがあります。

**推奨シーケンス**:
```
VDD(センサー) → VDD(nRF52840 SoC) → ファーム開始 → センサー初期化
                                        （10ms 以上ウェイト推奨）
```

Zephyr でのウェイト実装:

```c
/* main.c の最初 */
k_sleep(K_MSEC(50));   /* 外部センサー電源が安定するまで待機 */
sensor_init();
```


## センサー電源ゲーティングによる省電力

<!-- topic: GPIO でセンサーをON/OFFする -->

継続的にセンサーに電源を供給すると、センサーの待機電流が常に消費されます。使用時だけ GPIO でセンサー電源をON/OFFする「電源ゲーティング」で大幅に削減できます。

なお、2チップ構成（8.3節参照）でメインボードがスリープ状態に入る設計では、メインボードの電源制御が周辺回路（BLEモジュール含む）の電源を落としてしまうことがあります。その結果、「メインボードがスリープするとBLE接続が切れる」という問題が発生します。BLEモジュールは外部からの接続を常時受け付ける必要がある場合が多いため、BLEモジュールの電源はメインボードのスリープとは独立に供給し続ける回路設計が必要です。

```c
/* センサー電源制御GPIO */
static const struct gpio_dt_spec sensor_pwr =
    GPIO_DT_SPEC_GET(DT_ALIAS(sensor_pwr), gpios);

void sensor_power_on(void)
{
    gpio_pin_set_dt(&sensor_pwr, 1);
    k_sleep(K_MSEC(10));   /* センサー起動待ち */
}

void sensor_power_off(void)
{
    gpio_pin_set_dt(&sensor_pwr, 0);
}

/* 使い方 */
sensor_power_on();
sensor_read(&temp, &humi, &pres);
sensor_power_off();
/* → センサー測定時間（数ms）だけ通電、残りはゼロ */
```

BME280 の待機電流は約 0.1μA（通常動作時約 3.6μA）。センサーが多いほど電源ゲーティングの効果が大きくなります。
