## 8.2 I2C/SPIセンサーとの連携

<!-- topic: Zephyr sensor API の概要 -->

Zephyr は **Sensor API** という統一インターフェースを提供しており、センサーの種類に依らず同じAPIでデータ取得できます。BME280（温度・湿度・気圧）を例に説明します。

---

## prj.conf の設定

<!-- topic: Kconfig フラグ -->

```kconfig
# prj.conf
CONFIG_I2C=y         # I2C バス有効化
CONFIG_SENSOR=y      # Zephyr Sensor API 有効化
CONFIG_BME280=y      # BME280 ドライバ有効化
```

## デバイス取得と初期化

<!-- topic: sensor_sample_fetch / sensor_channel_get -->

```c
/* src/sensor.c */
#include <zephyr/kernel.h>
#include <zephyr/device.h>
#include <zephyr/drivers/sensor.h>
#include <zephyr/logging/log.h>

LOG_MODULE_REGISTER(sensor, LOG_LEVEL_INF);

/* Device Tree から BME280 デバイスを取得 */
static const struct device *bme280 =
    DEVICE_DT_GET_ONE(bosch_bme280);

void sensor_init(void)
{
    if (!device_is_ready(bme280)) {
        LOG_ERR("BME280 device not found or not ready");
        return;
    }
    LOG_INF("BME280 ready");
}

/* センサー値を読んで返す */
int sensor_read(int32_t *temp_mc,    /* milliCelsius */
                int32_t *humi_mpct,  /* milli-percent */
                int32_t *pres_pa)    /* Pascal */
{
    struct sensor_value temp, humi, pres;

    /* センサーをサンプリング */
    int err = sensor_sample_fetch(bme280);
    if (err) {
        LOG_ERR("Fetch failed (err %d)", err);
        return err;
    }

    /* 各チャンネルの値を取得 */
    sensor_channel_get(bme280, SENSOR_CHAN_AMBIENT_TEMP, &temp);
    sensor_channel_get(bme280, SENSOR_CHAN_HUMIDITY,     &humi);
    sensor_channel_get(bme280, SENSOR_CHAN_PRESS,        &pres);

    /* sensor_value → 整数変換（sensor_value.val1 + val2/1,000,000） */
    *temp_mc   = sensor_value_to_milli(&temp);
    *humi_mpct = sensor_value_to_milli(&humi);
    *pres_pa   = (int32_t)(sensor_value_to_double(&pres) * 100.0);

    LOG_INF("Temp: %d.%03d°C  Humi: %d.%03d%%  Pres: %d Pa",
            temp.val1, abs(temp.val2) / 1000,
            humi.val1, abs(humi.val2) / 1000,
            *pres_pa);

    return 0;
}
```

## BLE Notify との統合実装

<!-- topic: センサー値を毎秒Notifyで送る完全実装 -->

BLE サービス定義（6.2節のパターン）にセンサーデータを追加します。

```c
/* ペイロード構造体 */
struct env_payload {
    int16_t temp_cdeg;   /* × 100（2350 → 23.50℃） */
    uint16_t humi_cpct;  /* × 100（5510 → 55.10%） */
    uint32_t pres_pa;    /* Pascal */
} __packed;

static struct env_payload env_data;
static struct bt_gatt_notify_params notify_params;

/* 1秒ごとのワーク処理 */
static void sensor_notify_work(struct k_work *work)
{
    int32_t temp_mc, humi_mpct, pres_pa;

    if (sensor_read(&temp_mc, &humi_mpct, &pres_pa) != 0) {
        return;
    }

    env_data.temp_cdeg  = (int16_t)(temp_mc / 10);     /* mc→cdeg */
    env_data.humi_cpct  = (uint16_t)(humi_mpct / 10);  /* mpct→cpct */
    env_data.pres_pa    = (uint32_t)pres_pa;

    /* BLE Notify送信（6.5節で作成した notify_sensor_value() 相当） */
    bt_gatt_notify(NULL, SENSOR_CHRC_ATTR,
                   &env_data, sizeof(env_data));
}
```

## SPI センサー（IMU）の概要

<!-- topic: SPI の使い方の要点 -->

SPI センサー（加速度センサー・ジャイロスコープ等）も Device Tree に追記するだけでZephyrドライバが対応します。

```dts
/* SPI接続の加速度センサー（例：LSM6DSO） */
&spi1 {
    status = "okay";
    sck-pin  = <3>;
    mosi-pin = <4>;
    miso-pin = <28>;
    cs-gpios = <&gpio0 29 GPIO_ACTIVE_LOW>;

    lsm6dso@0 {
        compatible = "st,lsm6dso";
        reg = <0>;
        spi-max-frequency = <8000000>;
        label = "LSM6DSO";
    };
};
```

API は I2C センサーと同じ `sensor_sample_fetch()` / `sensor_channel_get()` です。
