# 第8章: 外部チップ連携（センサー・HCI・LTE統合）

## 章の概要

nRF52840 を中心に外部チップと連携する主要パターンを学ぶ。I2C/SPI センサー→BLE Notify によるデータ収集パターン、nRF52840 を BLE コントローラ（HCI）として既存 MCU から使うパターン、LTE モデム（nRF9160）と組み合わせるパターンの3つを実装する。

**想定ページ数**: 28-33ページ  
**前提章**: 第6章（ペリフェラル実装）、第7章（低消費電力設計）

---

## 節構成

### 8.1 外部チップ連携の全体像（2-3ページ）

- 1チップ構成（SoC単体）vs 2チップ構成（BLE SoC + メインMCU）の使い分け
- 接続インターフェースの種類（I2C / SPI / UART）と選択基準
- Zephyr の Device Tree（DTS）とドライバモデルの概要

### 8.2 I2C/SPIセンサーとの連携（6-7ページ）

- I2C接続の温度センサー（TMP102 / BME280）をZephyrドライバで読む
- `CONFIG_SENSOR=y` とデバイスノードの設定
- `sensor_sample_fetch()` / `sensor_channel_get()` API の使い方
- 読み取り値を BLE Notify でスマートフォンに送信するサンプル実装
- SPI接続の概要（IMUセンサー）

### 8.3 HCIインターフェース（nRF52840をBLEコントローラとして使う）（7-8ページ）

- HCI（Host Controller Interface）とは何か：Host と Controller の分離
- nRF52840 を HCI コントローラとして UART で接続する構成
- 対向MCU（STM32等）からのBLEスタック実装
- nRF52840 の hci_uart サンプル（NCS付属）を使ったセットアップ
- トラブルシューティング：ボーレート・フロー制御・パリティ

### 8.4 LTE + BLE 統合（nRF9160 + nRF52840）（7-8ページ）

- nRF9160（LTEモデム）+ nRF52840（BLE）の組み合わせ
- Nordic の nRF9161 DK または Thingy:91 の構成
- nRF9160 ↔ nRF52840 間の UART 通信（AT コマンドプロキシ）
- クラウドへのデータ送信 + BLE経由のローカルOTAフローの全体像

### 8.5 電源シーケンスと設計上の落とし穴（4-5ページ）

- GPIOレベル変換（3.3V vs 1.8V）
- I2Cのプルアップ抵抗の選び方
- 電源投入シーケンス（センサー>MCU>BLEの起動順）
- 外部チップの電源ゲーティング（センサーへの電源ON/OFFによる省電力）

### 8.6 まとめと第9章への橋渡し（1-2ページ）

- 外部チップ連携の構成パターン整理
- 第9章予告：iOS Core Bluetooth でセントラルアプリを実装する
