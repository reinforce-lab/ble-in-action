## まとめと第9章への橋渡し {#sec:ch8-summary}

<!-- topic: 章のまとめ -->

[@sec:ch8]では nRF52840 を中心とした外部チップ連携の3パターンを学びました。


## 構成パターン整理

| パターン | 構成 | 主なユースケース | 必要なZephyr設定 |
|---|---|---|---|
| **センサー連携** | nRF52840 + I2C/SPI センサー | 環境モニター・ウェアラブル | `CONFIG_SENSOR=y`、DTS overlay |
| **HCI接続** | メインMCU + nRF52840（Controller） | 既存システムへのBLE追加 | `hci_uart` サンプル、BlueZ など |
| **LTE統合** | nRF9160 + nRF52840 | フィールドセンサー・資産追跡 | `CONFIG_UART=y`、SMP設定 |


## 設計判断のフローチャート

```
要件を整理する

BLE のみ必要？
  └─YES→ 1チップ（nRF52840 単体）
  └─NO→ セルラー通信も必要？
          └─YES→ nRF9160 + nRF52840（LTE統合）
          └─NO→ 既存のメインMCUがある？
                  └─YES→ HCI 接続（nRF52840 を Controller として追加）
                  └─NO→ 1チップ（nRF52840 単体）
```

## 第9章へ：iOS Core Bluetooth でセントラルアプリを実装する

本章まではファームウェア（ペリフェラル側）を中心に学びました。[@sec:ch9]からはアプリケーション側（セントラル）に移ります。

[@sec:ch9]では **iOS の Core Bluetooth フレームワーク** を使い、第6〜8章で実装したカスタムサービスに接続・読み書き・Notify受信するアプリを実装します。

- `CBCentralManager` によるデバイスのスキャンと接続
- `CBPeripheral` の GATTサービス発見（`discoverServices` / `discoverCharacteristics`）
- Read / Write / Notify の実装
- バックグラウンドモードと電力消費の注意点
- Swift 5 / Xcode での実装
