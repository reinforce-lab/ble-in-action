## 本章で作るもの

第13章では温度・湿度・気圧を取得しiOSにリアルタイム表示する完全なシステムを実装します。

```
┌─────────────────────────────────────────────────────────────────┐
│                    温度計システム全体像                            │
│                                                                 │
│  BME280 センサー                                                  │
│   (温度/湿度/気圧)                                                │
│       │ I2C (400kHz)                                            │
│       ▼                                                         │
│  nRF52840                                                        │
│   Zephyrファームウェア                                             │
│   - 1秒ごとにBME280から測定                                       │
│   - GATTサービス:                                                 │
│     ・Temp/Hum/Press (Notify)                                    │
│     ・Alert Threshold (Read/Write)                               │
│       │ BLE (GATT Notify)                                       │
│       ▼                                                         │
│  iPhone                                                          │
│   SwiftUI + Core Bluetooth                                       │
│   - リアルタイムグラフ表示                                         │
│   - しきい値設定UI                                                │
│   - アラート通知                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## GATTサービス設計

| 属性 | UUID | プロパティ | フォーマット |
|---|---|---|---|
| Temperature & Humidity Service | `12345678-1234-5678-1234-56789abcdef0` | - | - |
| Temp/Hum Notify | `...EF2` | Notify | 4バイト: int16_t 温度×100, uint16_t 湿度×100 |
| Alert Threshold Write | `...EF3` | Read, Write | 2バイト: int16_t 温度しきい値×100 |
| Pressure Read | `...EF4` | Read, Notify | 4バイト: uint32_t 気圧 Pa |

温度データは `int16_t × 100` で表現します。たとえば 24.56°C は `2456` (0x0998) です。誤差なく2バイトで表現できます。

## ハードウェア接続

```
nRF52840 DK    BME280
─────────────────────
P0.26   ──────  SDA
P0.27   ──────  SCL
VDD     ──────  VDD (3.3V)
GND     ──────  GND
```

nRF52840の `CONFIG_I2C_0_NRF_TWIM` が I2C0 を管理します。DKではデフォルトでP0.26/P0.27がI2Cに割り当てられています。
