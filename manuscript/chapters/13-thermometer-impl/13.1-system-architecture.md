## 本章で作るもの

第13章では温度・湿度・気圧を取得しiOSにリアルタイム表示する完全なシステムを実装します。

```
┌─────────────────────────────────────────────────────────────────┐
│                    温度計システム全体像                            │
│                                                                 │
│  BME280 センサー                                                  │
│   (温度/湿度/気圧)                                                │
│       │ I2C (400kHz)                                            │
│       ▼                                                         │
│  nRF52840                                                        │
│   Zephyrファームウェア                                             │
│   - 1秒ごとにBME280から測定                                       │
│   - GATTサービス:                                                 │
│     ・Temp/Hum/Press (Notify)                                    │
│     ・Alert Threshold (Read/Write)                               │
│       │ BLE (GATT Notify)                                       │
│       ▼                                                         │
│  iPhone                                                          │
│   SwiftUI + Core Bluetooth                                       │
│   - リアルタイムグラフ表示                                         │
│   - しきい値設定UI                                                │
│   - アラート通知                                                  │
└─────────────────────────────────────────────────────────────────┘
```


## GATTサービス設計

| 属性 | UUID | プロパティ | フォーマット |
|---|---|---|---|
| Temperature & Humidity Service | `12345678-1234-5678-1234-56789abcdef0` | - | - |
| Temp/Hum Notify | `...EF2` | Notify | 4バイト: int16_t 温度×100, uint16_t 湿度×100 |
| Alert Threshold Write | `...EF3` | Read, Write | 2バイト: int16_t 温度しきい値×100 |
| Pressure Read | `...EF4` | Read, Notify | 4バイト: uint32_t 気圧 Pa |

温度データは `int16_t × 100` で表現します。たとえば 24.56°C は `2456` (0x0998) です。誤差なく2バイトで表現できます。


## ハードウェア接続

```
nRF52840 DK    BME280
─────────────────────
P0.26   ──────  SDA
P0.27   ──────  SCL
VDD     ──────  VDD (3.3V)
GND     ──────  GND
```

nRF52840の `CONFIG_I2C_0_NRF_TWIM` が I2C0 を管理します。DKではデフォルトでP0.26/P0.27がI2Cに割り当てられています。

## 開発のコツ: モックデバイスの活用

ファームウェアとiOSアプリを同時に開発する場合、片方が未完成の状態でもう片方を検証したい場面が頻繁に発生します。

**iOSアプリ先行の場合**: nRF Connect for Mobile（無料）の **Advertiser** 機能を使うと、nRF52840のファームウェアが未完成でも、iPhoneやAndroidをBLEペリフェラルとしてアドバタイズさせ、iOSアプリのスキャン・接続処理を検証できます。GATTサービスの定義もGUIで行えます。

**ファームウェア先行の場合**: nRF Connect for Mobile の **Scanner / Client** 機能で、ファームウェアのGATTサービスにRead/Write/Notifyを手動操作できます。iOSアプリの実装を待たずに、ファームウェアの動作を検証できます。

このように、**ファームウェアとアプリの開発を独立して進められる**ことがGATTの設計上の利点です。双方が合意したサービス仕様（UUID・データフォーマット）さえ決まっていれば、通信相手の完成を待つ必要はありません。


**まとめ**

- BME280 → I2C → nRF52840 → BLE Notify → iOS という構成
- 温度・湿度はint16_t/uint16_t × 100でエンコード（浮動小数不要）
- しきい値をiOSからWriteでき、超過時にアラートをNotify
