# 10.2 デバイス選択: requestDevice()

<!-- topic: requestDevice, フィルタオプション, BluetoothDevice, acceptAllDevices -->

---

## requestDevice() の基本

`navigator.bluetooth.requestDevice()` はブラウザでデバイス選択ダイアログを表示し、ユーザーが選んだ `BluetoothDevice` オブジェクトを返します。

```javascript
async function connectToDevice() {
    const device = await navigator.bluetooth.requestDevice({
        // 発見するデバイスのフィルタ
        filters: [
            { services: ['12345678-1234-5678-1234-56789abcdef0'] }
        ]
    });
    console.log('デバイス選択:', device.name);
    return device;
}

document.getElementById('connectBtn').addEventListener('click', connectToDevice);
```

`requestDevice()` は `Promise<BluetoothDevice>` を返します。ユーザーがキャンセルした場合は `DOMException: User cancelled the requestDevice() chooser.` がスローされます。

## フィルタオプション

`requestDevice()` に渡すオプションは、デバイス選択UIに表示するデバイスを絞り込みます。

### services フィルタ

最もよく使われるフィルタです。指定したサービスUUIDをアドバタイズしているデバイスだけがリストに表示されます。

```javascript
const device = await navigator.bluetooth.requestDevice({
    filters: [
        {
            services: ['12345678-1234-5678-1234-56789abcdef0']  // カスタムUUID
        }
    ]
});
```

16bit短縮形UUIDs（Bluetooth SIG標準サービス）も使用できます。

```javascript
// 心拍数サービス（SIG標準）でフィルタ
const device = await navigator.bluetooth.requestDevice({
    filters: [{ services: [0x180D] }]  // 0x180D = Heart Rate Service
});
```

### name / namePrefix フィルタ

デバイスのローカル名でフィルタリングします。

```javascript
const device = await navigator.bluetooth.requestDevice({
    filters: [
        { name: 'BLEInAction_Sensor' },              // 完全一致
        // または
        { namePrefix: 'BLEInAction' }                // 前方一致
    ]
});
```

### optionalServices: 追加サービスの宣言

接続後にアクセスするサービスのうち、`filters` に含まれていないものは `optionalServices` に宣言します。宣言していないサービスへはアクセスできません（セキュリティ上の制約）。

```javascript
const device = await navigator.bluetooth.requestDevice({
    filters: [
        { services: ['12345678-1234-5678-1234-56789abcdef0'] }
    ],
    optionalServices: [
        '0000180f-0000-1000-8000-00805f9b34fb'  // Battery Service（後でアクセスするために宣言）
    ]
});
```

### acceptAllDevices

開発・デバッグ時に、周囲のすべてのBLEデバイスを表示したい場合は `acceptAllDevices: true` を使います。ただし `filters` と同時には使えません。

```javascript
const device = await navigator.bluetooth.requestDevice({
    acceptAllDevices: true,
    optionalServices: ['12345678-1234-5678-1234-56789abcdef0']
});
```

> **本番アプリでは `acceptAllDevices: true` は避けてください**。セキュリティ上のリスクに加え、ユーザーに無関係なデバイスが大量に表示されてUXが悪化します。

## BluetoothDeviceオブジェクト

`requestDevice()` が解決すると `BluetoothDevice` オブジェクトが返ります。主要なプロパティは次のとおりです。

| プロパティ | 型 | 内容 |
|---|---|---|
| `id` | `string` | ブラウザが割り当てるデバイスID（BLEアドレスではない）|
| `name` | `string?` | デバイスのローカル名（アドバタイズデータから）|
| `gatt` | `BluetoothRemoteGATTServer` | GATT操作のエントリポイント |
| `watchingAdvertisements` | `boolean` | アドバタイズ監視中かどうか |

```javascript
const device = await navigator.bluetooth.requestDevice({
    filters: [{ services: ['12345678-1234-5678-1234-56789abcdef0'] }]
});

console.log('デバイスID:', device.id);
console.log('デバイス名:', device.name ?? '（名前なし）');
console.log('GATT接続済み:', device.gatt.connected);
```

## 切断イベントの監視

`BluetoothDevice` は `gattserverdisconnected` イベントを発行します。接続断の検知と自動再接続に使います。

```javascript
async function setupDevice() {
    const device = await navigator.bluetooth.requestDevice({
        filters: [{ services: ['12345678-1234-5678-1234-56789abcdef0'] }]
    });

    // 切断イベントを登録
    device.addEventListener('gattserverdisconnected', () => {
        console.log('接続が切れました。再接続を試みます...');
        reconnect(device);
    });

    return device;
}

async function reconnect(device) {
    // 最大3回リトライ
    for (let attempt = 0; attempt < 3; attempt++) {
        try {
            await device.gatt.connect();
            console.log('再接続成功');
            return;
        } catch (error) {
            console.log(`再接続失敗 (${attempt + 1}/3):`, error.message);
            await new Promise(resolve => setTimeout(resolve, 1000));
        }
    }
    console.error('再接続を断念しました');
}
```

## デバイスの再利用

同じデバイスへの再接続時に、毎回 `requestDevice()` を呼ぶ必要はありません。一度取得した `BluetoothDevice` オブジェクトは変数に保持しておき、`device.gatt.connect()` を再度呼ぶだけで再接続できます。

```javascript
let bleDevice = null;  // ページ変数として保持

async function handleConnectClick() {
    if (!bleDevice) {
        // 初回だけ requestDevice() でユーザーにデバイスを選ばせる
        bleDevice = await navigator.bluetooth.requestDevice({
            filters: [{ services: ['12345678-1234-5678-1234-56789abcdef0'] }]
        });
    }
    // 以降は保持済みのデバイスで再接続
    const server = await bleDevice.gatt.connect();
    return server;
}
```

## エラーハンドリング

`requestDevice()` での主要なエラーパターンです。

```javascript
try {
    const device = await navigator.bluetooth.requestDevice({
        filters: [{ services: ['12345678-1234-5678-1234-56789abcdef0'] }]
    });
} catch (error) {
    if (error.name === 'NotFoundError') {
        console.log('デバイスが見つからないかキャンセルされました');
    } else if (error.name === 'SecurityError') {
        console.log('HTTPSが必要です、またはUser Gestureがありません');
    } else if (error.name === 'NotSupportedError') {
        console.log('このブラウザはWeb Bluetooth APIをサポートしていません');
    } else {
        console.error('予期しないエラー:', error);
    }
}
```

### ブラウザのBluetooth対応確認

```javascript
// Web Bluetooth APIの対応確認
if (!navigator.bluetooth) {
    alert('このブラウザはWeb Bluetooth APIに対応していません。\nChrome/Edgeをお使いください。');
    return;
}
```

---

**まとめ**

- `requestDevice()` はユーザーの操作イベントから呼ぶ（User Gesture必須）
- `filters.services` に対象サービスUUIDを指定してデバイスを絞り込む
- `optionalServices` に後でアクセスするサービスをすべて宣言する
- `acceptAllDevices: true` は開発時のみ。本番では使わない
- `BluetoothDevice` を変数に保持しておけば再接続時に再利用できる
