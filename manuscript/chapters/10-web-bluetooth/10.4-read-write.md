## 値の読み出し（readValue）

`characteristic.readValue()` で値を読み出します。結果は `DataView` オブジェクトとして返ります。

```javascript
async function readTemperature(tempChar) {
    // DataView を取得
    const dataView = await tempChar.readValue();

    // DataViewから値をパース（リトルエンディアン）
    // Int16: 2バイトのリトルエンディアン符号付き整数
    const rawTemp = dataView.getInt16(0, true);   // true = little-endian
    const celsius = rawTemp / 100.0;

    console.log(`温度: ${celsius.toFixed(2)}°C`);
    return celsius;
}
```

`true` はリトルエンディアンを指定します。nRF52840（ARM Cortex-M4, リトルエンディアン）から送られるデータは通常リトルエンディアンです。

## DataViewのパース方法

`DataView` はバイト列を様々な数値型として読み出せます。

| メソッド | バイト数 | 例 |
|---|---|---|
| `getInt8(offset)` | 1 | 符号あり8bit整数 |
| `getUint8(offset)` | 1 | 符号なし8bit整数 |
| `getInt16(offset, le)` | 2 | 符号あり16bit整数 |
| `getUint16(offset, le)` | 2 | 符号なし16bit整数 |
| `getInt32(offset, le)` | 4 | 符号あり32bit整数 |
| `getFloat32(offset, le)` | 4 | 32bit浮動小数点数 |

```javascript
// 環境センサーデータ: 温度(Int16 LE) + 湿度(Uint16 LE) = 4バイト
function parseSensorData(dataView) {
    // バイト0-1: 温度（Int16 LE, 0.01°C単位）
    const rawTemp    = dataView.getInt16(0, true);
    const tempC      = rawTemp / 100.0;

    // バイト2-3: 湿度（Uint16 LE, 0.01%単位）
    const rawHumid   = dataView.getUint16(2, true);
    const humidity   = rawHumid / 100.0;

    return { tempC, humidity };
}
```

## 値の書き込み（writeValue）

`characteristic.writeValue()` でデータを書き込みます。引数には `ArrayBuffer` または `DataView` を渡します。

### writeValue（廃止予定）/ writeValueWithResponse / writeValueWithoutResponse

Web Bluetooth APIでは、Core Bluetoothの `CBCharacteristicWriteWithResponse` / `WithoutResponse` に対応する2つのメソッドがあります。

| メソッド | 対応するATT操作 | 確認応答 |
|---|---|---|
| `writeValueWithResponse(data)` | ATT Write Request | あり（推奨）|
| `writeValueWithoutResponse(data)` | ATT Write Command | なし |

```javascript
// 確認あり書き込み（設定変更や重要なコマンド）
async function setThreshold(char, celsius) {
    // ArrayBufferにリトルエンディアンで格納
    const buffer = new ArrayBuffer(2);
    const view   = new DataView(buffer);
    view.setInt16(0, Math.round(celsius * 100), true);   // LE Int16

    await char.writeValueWithResponse(buffer);
    console.log(`閾値設定: ${celsius}°C`);
}

// 確認なし書き込み（リアルタイム制御コマンド）
async function setLED(char, isOn) {
    const buffer = new Uint8Array([isOn ? 0x01 : 0x00]).buffer;
    await char.writeValueWithoutResponse(buffer);
}
```

> **注意**: 旧メソッド `writeValue()` は内部的に `writeValueWithResponse` と同じ動作をしますが、仕様で廃止予定です。新しいコードでは `writeValueWithResponse` / `writeValueWithoutResponse` を使います。

## ArrayBufferとUint8Arrayの使い方

書き込みデータの準備方法をまとめます。

```javascript
// 方法1: Uint8Array から作成（シンプル）
const uint8 = new Uint8Array([0x01, 0x02, 0x03]);
await char.writeValueWithResponse(uint8.buffer);

// 方法2: ArrayBuffer + DataView（数値型の設定が正確）
const buffer = new ArrayBuffer(4);
const dv = new DataView(buffer);
dv.setUint8(0,   0x01);
dv.setUint16(1, 0x0203, true);  // LE
dv.setUint8(3,   0x04);
await char.writeValueWithResponse(buffer);

// 方法3: hex文字列 → Uint8Array
function hexToBytes(hex) {
    return new Uint8Array(hex.match(/.{2}/g).map(b => parseInt(b, 16)));
}
const bytes = hexToBytes('010203').buffer;
await char.writeValueWithResponse(bytes);
```

## 実装例: センサーUIのHTML+JavaScript

nRF52840の温度センサーを読み取るシンプルなWebアプリの完全なサンプルです。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>BLE 温度センサー</title>
    <style>
        body { font-family: sans-serif; text-align: center; padding: 20px; }
        #temp { font-size: 3em; margin: 20px 0; }
        button { font-size: 1.2em; padding: 10px 20px; cursor: pointer; }
    </style>
</head>
<body>
    <h1>BLE 温度センサー</h1>
    <div id="temp">--.-°C</div>
    <button id="connectBtn">接続</button>
    <button id="readBtn" disabled>温度を読む</button>
    <button id="disconnectBtn" disabled>切断</button>

    <script>
    const SERVICE_UUID = '12345678-1234-5678-1234-56789abcdef0';
    const TEMP_UUID    = '12345678-1234-5678-1234-56789abcdef1';

    let device = null;
    let tempChar = null;

    document.getElementById('connectBtn').addEventListener('click', async () => {
        try {
            device = await navigator.bluetooth.requestDevice({
                filters: [{ services: [SERVICE_UUID] }]
            });
            device.addEventListener('gattserverdisconnected', onDisconnected);

            const server  = await device.gatt.connect();
            const service = await server.getPrimaryService(SERVICE_UUID);
            tempChar       = await service.getCharacteristic(TEMP_UUID);

            document.getElementById('readBtn').disabled = false;
            document.getElementById('disconnectBtn').disabled = false;
            document.getElementById('connectBtn').disabled = true;
            console.log('接続完了');
        } catch (e) {
            console.error('接続エラー:', e.message);
        }
    });

    document.getElementById('readBtn').addEventListener('click', async () => {
        if (!tempChar) return;
        try {
            const value = await tempChar.readValue();
            const raw   = value.getInt16(0, true);
            const temp  = raw / 100.0;
            document.getElementById('temp').textContent = temp.toFixed(2) + '°C';
        } catch (e) {
            console.error('読み取りエラー:', e.message);
        }
    });

    document.getElementById('disconnectBtn').addEventListener('click', () => {
        if (device && device.gatt.connected) {
            device.gatt.disconnect();
        }
    });

    function onDisconnected() {
        console.log('切断されました');
        document.getElementById('readBtn').disabled = true;
        document.getElementById('disconnectBtn').disabled = true;
        document.getElementById('connectBtn').disabled = false;
        document.getElementById('temp').textContent = '--.-°C';
        tempChar = null;
    }
    </script>
</body>
</html>
```

このコードをHTMLファイルとして保存し、`python3 -m http.server 3000` で起動して `http://localhost:3000` にChromeでアクセスすれば動作します。

---

**まとめ**

- `readValue()` は `DataView` を返す。`getInt16(0, true)` などでバイト列をパース
- 書き込みは `writeValueWithResponse()` と `writeValueWithoutResponse()` を用途で使い分ける
- データは `ArrayBuffer`/`Uint8Array`/`DataView` で準備する
- リトルエンディアンを扱う際は各メソッドの第2引数に `true` を渡す
