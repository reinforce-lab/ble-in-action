## 8.3 スキャンして目的の製品へ接続する {#sec:ch8-scan-connect}

PeripheralはAdvertisement Dataを送信し、Centralはスキャンによって候補を発見します。Device Control ServiceのUUIDがAdvertisement Dataへ含まれる構成なら、`scanForPeripherals(withServices:options:)`へService UUIDを指定して候補を絞れます。

```swift
private let serviceUUID = CBUUID(
    string: "7A4A0001-6E2C-4B7A-9A32-2A1D6F3C9000"
)

private func startScanning() {
    guard central.state == .poweredOn else { return }
    state = .scanning
    central.scanForPeripherals(
        withServices: [serviceUUID],
        options: [CBCentralManagerScanOptionAllowDuplicatesKey: false]
    )
}
```

Service UUIDを指定しないスキャンは、周囲の広い候補を調査するときには使えます。しかし、製品アプリでは不要な発見Callbackが増えます。バックグラウンド動作にも制約があるため、製品を識別できるService UUIDをAdvertisement Dataへ入れられるなら、フィルターとして利用します。

### 発見した情報だけで所有者を決めない

発見結果は`centralManager(_:didDiscover:advertisementData:rssi:)`へ届きます。

```swift
func centralManager(
    _ central: CBCentralManager,
    didDiscover peripheral: CBPeripheral,
    advertisementData: [String: Any],
    rssi RSSI: NSNumber
) {
    guard state == .scanning else { return }

    let localName = advertisementData[
        CBAdvertisementDataLocalNameKey
    ] as? String

    print("discover id=\(peripheral.identifier) name=\(localName ?? "-") rssi=\(RSSI)")
    select(peripheral)
}
```

Local Nameは表示や候補の絞り込みには使えますが、認証情報ではありません。RSSIも距離そのものではなく、送信電力、向き、人体、壁、反射などで変動します。近いデバイスを選ぶ補助にはなりますが、「最もRSSIが強いから利用者の所有物」とは判断できません。所有権と認可は第12章で扱います。

`CBPeripheral.identifier`は、iOSがPeripheralを識別するためのUUIDです。BLEアドレスをそのまま表すものとして扱わず、サーバー側の製品IDとも区別します。

### 候補を選んでから接続する

接続するPeripheralを決めたら、スキャンを止め、参照を保持して接続を開始します。

```swift
private var peripheral: CBPeripheral?

private func select(_ candidate: CBPeripheral) {
    central.stopScan()
    peripheral = candidate
    state = .connecting
    central.connect(candidate, options: nil)
}

func centralManager(
    _ central: CBCentralManager,
    didConnect peripheral: CBPeripheral
) {
    peripheral.delegate = self
    state = .discovering
    peripheral.discoverServices([serviceUUID])
}

func centralManager(
    _ central: CBCentralManager,
    didFailToConnect peripheral: CBPeripheral,
    error: Error?
) {
    state = .failed(error?.localizedDescription ?? "接続に失敗しました")
}
```

`connect`の呼び出しは接続要求の開始です。接続成立は`didConnect`で確認します。接続前に`CBPeripheral`への参照を失うと、アプリ側で接続対象を管理できなくなるため、接続セッションの所有者が保持します。

複数台を扱う製品では、発見した候補、選択した接続対象、接続済みPeripheralを別のCollectionで管理します。本章では一台へ接続する構成に絞ります。
