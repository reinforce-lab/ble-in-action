## 5.1 nRF52840と開発環境の全体像

<!-- topic: なぜnRF52840か -->

Part 2では、BLEプロトコルスタックをATT/GATTまで積み上げてきました。ここからはそれを「動くファームウェア」として実装します。本書のファームウェア開発には**Nordic Semiconductor nRF52840**を使います。

nRF52840を選ぶ理由は3つあります。

**1. BLE + 周辺機能のオールインワン**  
nRF52840はARM Cortex-M4F（64MHz）とBLE 5.3のコントローラを1チップに搭載したSoC（System on Chip）です。さらにUSB 2.0フルスピード、1MB Flash、256KB SRAM、最大48ピンのGPIOを備えています。第4章で学んだHCI境界で言えば、**ControllerとHostを1チップで動かせる**構成です。USBドングルのようにHCIを物理的に引き出す必要がなく、すべてのBLEスタックがSoC内で動きます。

BLEのSoCが安価に製造できるのは、スマートフォンのプロセッサのような最先端プロセスを必要としない設計だからです。BLEの通信速度は最大2Mbpsほどで、演算処理も小規模です。そのため、十分に安価な一般的な半導体プロセスで製造でき、IoTデバイスのコスト要件を満たせます。

**2. nRF Connect SDK（Zephyr RTOS）の充実度**  
NordicはnRF Connect SDKとしてZephyr RTOSをベースにしたSDKと豊富なサンプルを提供しています。BLEの各プロファイルのサンプルがすぐに試せ、本番製品への移行パスも明確です。

**3. 世界的なシェアと資料の豊富さ**  
ウェアラブル・IoTデバイスで広く採用されており、フォーラム・GitHubの事例・DevZoneの技術情報が豊富です。困ったときに答えが見つかりやすい環境は、開発効率に直結します。

## nRF Connect SDK 3.0の構成

<!-- topic: SDK の構造 -->

**nRF Connect SDK（以下NCS）**はいくつかのコンポーネントで構成されています。

```
nRF Connect SDK 3.0 の構成

┌─────────────────────────────────────────────────────┐
│  アプリケーション（本書で書くコード）                │
├─────────────────────────────────────────────────────┤
│  nRF Connect SDK（Nordicが提供するHAL・ライブラリ）  │
│  ├─ Bluetooth stack（Zephyr Bluetooth + Nordic拡張） │
│  ├─ nRF HAL（nRF52840のペリフェラルドライバ）         │
│  └─ サンプルアプリ群（peripheral, central, etc.）   │
├─────────────────────────────────────────────────────┤
│  Zephyr RTOS（カーネル・デバイスドライバ・Kconfig）  │
├─────────────────────────────────────────────────────┤
│  nRF52840 SoC（Cortex-M4F + BLE Controller + HW）   │
└─────────────────────────────────────────────────────┘
```

**Zephyr RTOS** はLinux Foundationが管理するオープンソースのRTOSで、NCSはこれをベースにしています。スレッド管理・タイマー・割り込み処理・デバイスドライバを提供し、**Kconfig**（`CONFIG_*`フラグ群）でビルドに含めるコンポーネントをメニュー形式で選択できます。

**west** はZephyr/NCSのビルド・フラッシュツールです。`west build`でビルド、`west flash`で書き込み、`west update`で依存関係の更新を行います。

## 開発ツールの全体像

<!-- topic: ツールスタック -->

```
開発ツールの全体図

[PC（macOS / Windows / Linux）]
  │
  ├─ VS Code + nRF Connect for VS Code 拡張機能
  │     → プロジェクト管理・コード編集・ビルド実行・フラッシュ書き込み
  │
  ├─ nRF Connect for Desktop
  │     → Toolchain Manager（SDK・GCCツールチェーン管理）
  │     → Programmer アプリ（HEXファイルの書き込み）
  │     → Serial Terminal（RTT / UARTログ確認）
  │
  └─ J-Link / nRF Command Line Tools
        → nrfjprog（コマンドラインからのフラッシュ書き込み・消去）
        → JLinkExe / JLinkRTTViewer（デバッガ接続・RTTログ）

  USB（J-Link）
  │
[nRF52840 DK（PCA10056）]
  │
  ├─ J-Link OB（オンボードデバッガ）
  ├─ nRF52840 SoC
  ├─ ボタン × 4、LED × 4
  └─ アンテナ（PCBアンテナ一体型）
```

これらすべてを無料で入手・利用できます。nRF52840 DK（開発ボード）は購入が必要ですが（$35〜$40程度）、ソフトウェアはすべてNordicが無償提供しています。
