## 開発環境のセットアップ

<!-- topic: インストール前の前提確認 -->

開発環境のセットアップを始める前に、PCに必要なものが揃っているか確認します。

| 必要なもの | 確認コマンド / 方法 | 最低バージョン |
|---|---|---|
| Git | `git --version` | 2.x以上 |
| VS Code | アプリケーションとして起動 | 最新版推奨 |
| nRF Connect for Desktop | Nordic公式サイトからDL | v4.4以上 |
| USB Cケーブル（J-Link用） | 目視確認 | — |

**macOSの場合**: Xcodeコマンドラインツール（`xcode-select --install`）が必要です。macOS 14以降はデフォルトでインストールされていることが多いですが、ツールが見つからないエラーが出た場合はこのコマンドを実行してください。

**Windowsの場合**: コントロールパネル → システム → 詳細設定 → 環境変数 → PATH の長さが260文字を超えるとビルドに失敗することがあります。nRF Connect SDKはフォルダ階層が深いため、`C:\ncs\` のような短いパスへのインストールを推奨します。


## nRF Connect for Desktop のインストールとToolchain Manager

<!-- topic: Toolchain Manager によるセットアップ -->

OpenNordicの公式サイト（https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-Desktop）から nRF Connect for Desktop をダウンロードしてインストールします。

インストール後、アプリを起動して**Toolchain Manager**を見つけてインストールします。Toolchain Managerは、SDKのバージョンとそれに対応するGCC Arm EmbeddedツールチェーンをセットでPCに管理してくれるツールです。

```
nRF Connect for Desktop → Toolchain Manager を開く
  → 「nRF Connect SDK v3.0.0」の横の [Install] ボタンをクリック
  → ツールチェーン（GCC Arm Embedded, CMake, Ninja, west）が自動インストールされる
  → インストール完了後、[Open Visual Studio Code] ボタンが現れる
```

このインストールには10〜30分かかります（インターネット速度による）。インストール先は自動的に決まります（macOSなら `~/ncs/`、Windowsなら `C:\ncs\`）。


## west コマンドの確認

<!-- topic: west の基本 -->

インストールが完了したら、Toolchain Manager の「Generate environment script」または「Open Terminal」機能でツールチェーンのPATHを設定した端末を開き、`west`コマンドが使えることを確認します。

```bash
# nRF Connect for Desktop → Toolchain Manager → Open Terminal
$ west --version
West version: v1.x.x

$ arm-none-eabi-gcc --version
arm-none-eabi-gcc (GNU Arm Embedded Toolchain) 12.x.x ...
```

`west`はPythonスクリプトで動作するビルドフロントエンドです。主要なコマンドを把握しておきましょう。

```bash
west build -b nrf52840dk_nrf52840   # ボードを指定してビルド
west flash                           # 接続中のボードに書き込む
west flash --recover                 # SoCの保護を解除してから書き込む
west build -t guiconfig              # KconfigのGUI設定画面を開く
```


## nRF Connect for VS Code 拡張機能のインストール

<!-- topic: VS Code 拡張機能 -->

VS Codeを開き、拡張機能（Extensions）パネルから「nRF Connect for VS Code」拡張機能をインストールします。この拡張機能1つが以下をまとめて提供します。

- プロジェクトの作成（サンプルから / テンプレートから）
- ビルドとフラッシュのGUI操作
- Kconfig（`prj.conf`）のグラフィカルな設定画面
- Device Tree（`*.dts`）のシンタックスハイライト

インストール後、VS Codeサイドバーに「nRF CONNECT」パネルが追加されます。パネル内の「Toolchain Manager」でNCSのインストールが確認でき、「Active SDK」に `v3.0.0` が選択されていれば準備完了です。


## よくあるトラブルと対処

<!-- topic: セットアップ時のトラブルシューティング -->

**python3 / pip not found（macOS）**  
macOS Ventura以降では標準Pythonが削除されています。`brew install python3`でインストールし、ツールチェーンのactivate.shを再度実行します。

**SSL証明書エラー（企業プロキシ環境）**  
`west update` がSSLエラーで失敗する場合は、企業のCA証明書をシステムに登録するか、`git config --global http.sslVerify false`（一時的な回避策）を試してください。

**nrfjprog: device not found**  
nRF Command Line Toolsがインストールされていない場合に発生します。Toolchain Managerに含まれていますが、見つからない場合はNordicのダウンロードページから別途インストールしてください。
