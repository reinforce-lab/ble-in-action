## nRF Sniffer とは

**nRF Sniffer for Bluetooth LE** はNordic Semiconductorが提供する無料のBLEパケットキャプチャツールです。nRF52840 / nRF52 DKにSnifferファームウェアを書き込み、PCのWiresharkでBLEパケットをリアルタイムに解析できます。

必要なもの：
- nRF52840 DK（またはnRF52 DK）
- PCにインストールされた Wireshark 3.x以上
- nRF Sniffer プラグイン（Nordic提供）


## Snifferファームウェアの書き込み

```bash
# 1. nRF Sniffer パッケージをダウンロード
# https://www.nordicsemi.com/Products/Development-tools/nrf-sniffer-for-bluetooth-le
# → "nRF-Sniffer-for-Bluetooth-LE-*.zip" をダウンロードして展開

# 2. Snifferファームウェアの書き込み
# nRF52840 DKをUSBで接続してから:
nrfjprog --program hex/sniffer_nrf52840dk_nrf52840.hex --chiperase --verify

# または nrfutil で書き込む
nrfutil device program --firmware hex/sniffer_nrf52840dk_nrf52840.hex

# 3. Snifferが接続されているシリアルポートを確認
ls /dev/tty.usbmodem*   # macOS
# /dev/tty.usbmodem1411
```


## Wireshark プラグインのインストール

```bash
# 1. プラグインをWiresharkのプラグインディレクトリにコピー
# macOS:
cp extcap/nrf_sniffer_ble.py \
    ~/.config/wireshark/extcap/

cp extcap/nrf_sniffer_ble.bat \
    ~/.config/wireshark/extcap/      # (Windowsのみ)

# 2. プラグインに実行権限を付与 (macOS/Linux)
chmod +x ~/.config/wireshark/extcap/nrf_sniffer_ble.py

# 3. Python依存ライブラリのインストール
pip3 install pyserial

# 4. Wiresharkを再起動
```


## Wiresharkでのキャプチャ開始

1. Wiresharkを起動
2. インターフェース一覧に **nRF Sniffer for Bluetooth LE** が表示される
3. 「Options（歯車アイコン）」クリック → シリアルポートを選択（`/dev/tty.usbmodem1411`）
4. キャプチャ開始ボタンをクリック

```
Wireshark インターフェース例:
  nRF Sniffer for Bluetooth LE [COM3]     ← Windows
  nRF Sniffer for Bluetooth LE [/dev/tty.usbmodem1411]  ← macOS
```


## 特定デバイスのフィルタ

デフォルトでは周囲のすべてのBLEパケットをキャプチャします。対象デバイスだけをフィルタするにはSnifferのUIかBD_Addressでフィルタします。

Wiresharkの表示フィルタ（Display Filter）:
```
# アドバタイズパケットのみ
btle.advertising_header

# GATTパケットのみ
btatt

# 特定のBD_Address（ペリフェラル）のみ
btle.advertising_address == c0:26:da:xx:xx:xx

# ATT Writeのみ
btatt.opcode == 0x52
```


## Wireshark のBLE設定

```
Wireshark → Edit → Preferences → Protocols → BTLE
  ☑ Try to decrypt encrypted packets  (ペアリングあり環境)
  Legacy Key:  [Sniffer取得のLTKをここに貼る]
```

- `btatt` フィルタでGATTパケットのみに絞り込んで解析
