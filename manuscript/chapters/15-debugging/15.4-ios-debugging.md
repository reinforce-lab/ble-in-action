## iOS PacketLogger

**PacketLogger** はApple提供のBTログ解析ツール（macOS用）です。iPhoneのBluetooth HCIログをリアルタイムで取得・解析できます。

### セットアップ

```
1. Apple Developer サイトから "Additional Tools for Xcode" をダウンロード
   https://developer.apple.com/download/more/
   → "Additional Tools for Xcode N.N" の .dmg を開く

2. Hardware フォルダ内の PacketLogger.app をアプリケーションフォルダに移動

3. iPhone を Mac に USB 接続

4. PacketLogger を起動 → File → New iOS Trace
   → 接続されている iPhone を選択

5. iPhone で BLE アプリを操作すると HCI ログが取得される
```

## Core Bluetooth のデバッグログ

環境変数 `COREBLUETOOTHD_LOGGING=1` を設定するとCore Bluetoothの内部ログが詳細に出力されます。

```bash
# Xcodeのスキームでこの環境変数を設定
# Xcode → Edit Scheme → Run → Environment Variables
# COREBLUETOOTHD_LOGGING = 1
```

## Xcode Instruments

**Instruments** の **CoreBluetooth** テンプレートでBLE操作の時系列をビジュアルに確認できます。

```
1. Xcode → Product → Profile (Cmd+I)
2. Instruments 起動 → CoreBluetooth テンプレートを選択
3. Record ボタンで iPhone上のアプリを実行
4. タイムラインで接続・発見・Read/Write/Notifyの時刻を確認
```


## よく見るiOSデバッグパターン

### パターン1: `CBManagerStatePoweredOff`

```swift
func centralManagerDidUpdateState(_ central: CBCentralManager) {
    switch central.state {
    case .poweredOff:
        // ユーザーにBluetoothをオンにするよう案内
        showAlert("Bluetoothをオンにしてください")
    case .unauthorized:
        // Info.plistのNSBluetoothAlwaysUsageDescriptionが不足
        showAlert("BLEの使用許可が必要です")
    case .poweredOn:
        startScan()
    default:
        break
    }
}
```

### パターン2: サービスが見つからない

PacketLoggerで `GATT: Disc All Primary Services Response` を確認します。サービスUUIDが表示されない場合はファームウェアの `BT_GATT_SERVICE_DEFINE` を確認してください。

### パターン3: Notifyが1回しか来ない

CCCD書き込みは確認できているが、その後Notifyが来ない場合はファームウェアの `bt_gatt_notify()` の戻り値を確認します。`-ENOTCONN` 以外のエラーが出ていないか Zephyr ログを確認してください。


**まとめ**

- PacketLogger でiPhone → nRF52840 の HCI全ログをキャプチャできる
- `COREBLUETOOTHD_LOGGING=1` でCore Bluetoothの内部ログを有効化
- Instrumentsの CoreBluetooth テンプレートで時系列を視覚化
- `CBManagerState` の確認は全デバッグの起点
