## よくある質問

### Q1: BLE で何メートル届きますか？

**A**: 規格上の最大通信距離は約100mですが、実用的な目安は次のとおりです。

| 環境 | 目安距離 |
|---|---|
| 見通し屋外 | 30〜100m |
| 一般室内 | 10〜30m |
| 鉄筋コンクリート越し | 3〜10m（壁の枚数による） |

nRF52840 では `bt_le_adv_param` の TX Power を `+8dBm` に設定することで到達距離を伸ばせますが、電池消費も増えます。


### Q2: iBeacon は Android でも使えますか？

**A**: iBeacon は Apple 独自の仕様ですが、Android から受信することは可能です。ただし、iOS の `CoreLocation` のような専用APIがないため、BLEスキャン結果から手動でパースします。

```kotlin
// Android: iBeacon パース例
val manufacturerData = scanRecord.getManufacturerSpecificData(0x004C)  // Apple社ID
if (manufacturerData != null && manufacturerData[0] == 0x02.toByte()) {
    // iBeacon フレームを手動パース
    val major = ((manufacturerData[18].toInt() and 0xFF) shl 8) or
                 (manufacturerData[19].toInt() and 0xFF)
    val minor = ((manufacturerData[20].toInt() and 0xFF) shl 8) or
                 (manufacturerData[21].toInt() and 0xFF)
    val txPower = manufacturerData[22].toInt()  // Signed byte
}
```


### Q3: nRF52840 以外でも本書の内容は使えますか？

**A**: Zephyr RTOS をサポートするマイコンであれば、本書のコードの多くがそのまま流用できます。例えば以下のボードで動作確認されています: Nordic nRF5340, ST STM32WB55, NXP i.MX RT1060。

プラットフォーム固有の部分（DTS設定、ドライバ設定）は各ボードのサポートページを参照してください。


### Q4: BLE と Wi-Fi を同時に使えますか？

**A**: nRF52840単体ではWi-Fiをサポートしていません。Wi-Fiと組み合わせる場合は、BLE-Wi-Fiブリッジとして動作するSoCか、ESP32（Wi-Fi+BLE両対応）を検討してください。


### Q5: OTA DFU 中にバッテリーが切れたらどうなりますか？

**A**: MCUBoot を使う場合、転送中に電源が切れても **Primary** スロットのファームウェアは壊れません。再起動すると古いファームウェアで動作し続けます（Swap は完了時にのみ行われる）。ただし、転送の途中状態は破棄されるため、OTAを最初からやり直す必要があります。

### Bluetooth SIG への参加

製品を市場に出す場合、**Bluetooth SIG** のメンバーシップが必要です（無償のAdoptee会員でも認定プロセスへのアクセス可能）。

- [https://www.bluetooth.com/develop-with-bluetooth/join/](https://www.bluetooth.com/develop-with-bluetooth/join/)

### Bluetooth 5.4 以降の新機能

- **PAwR** (Periodic Advertising with Responses): 双方向のビーコン通信
- **EATT** (Enhanced ATT): 並列ATT通信（スループット向上）
- **LE Audio / LC3 コーデック**: 次世代低遅延Bluetoothオーディオ

### Matter / Thread との連携

Matter（旧 Project CHIP）はWi-Fi、Thread、Ethernetを統合するスマートホーム標準です。BLEは **Matter のコミッショニング（初期設定）** に使用されています。Thread はBLEと周波数帯が重なりますが、M5Stack NanoCや Nordic nRF5340はMatterとBLEを同時にサポートします。
