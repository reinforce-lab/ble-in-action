## データ送受信の問題 {#sec:data-issues}

<!-- topic: MTU超過, CCCD未設定, バイトオーダー, データ型変換 -->


## よくある問題: データが壊れている

```
症状: Notifyで受信した温度が "655.35°C" などの異常値になる

原因: バイトオーダーの取り違え

ファームウェア: Little-endian で送信
iOS: Big-endianとして解釈

NG:
let rawTemp = Int16(bigEndian: data.withUnsafeBytes { $0.load(as: Int16.self) })

OK:
let rawTemp = Int16(littleEndian: data.withUnsafeBytes { $0.load(as: Int16.self) })
```

**nRF52840はLittle-endianアーキテクチャ（ARM Cortex-M）** です。すべてのデータはLittle-endianとして扱います。


## よくある問題: 20バイト以上のデータが切れる

```
症状: 20バイトを超えるデータを送ると後半が欠落する

原因: ATTのデフォルトMTUは23バイト（ペイロード20バイト）
      MTU交換を行わずに長データを送ろうとしている

対策:
1. MTU内に収まるようデータを分割
   または
2. MTU交換後にまとめて送る

Zephyr側でのMTU交換後の最大ペイロード:
  exchange_params.func = exchange_func;
  bt_gatt_exchange_mtu(conn, &exchange_params);

  void exchange_func(struct bt_conn *conn, uint8_t err, ...)
  {
      uint16_t mtu = bt_gatt_get_mtu(conn);
      max_payload = mtu - 3;   // ATT header 3bytes
  }
```


## よくある問題: Writeしても値が変わらない

```
症状: Write Requestを送ってもデバイス側に反映されない

確認ポイント:
1. Write ResponseがあるかWiresharkで確認
2. Writeハンドラ関数の戻り値を確認
3. GATTサービス定義でBT_GATT_PERM_WRITEが設定されているか

NG:
BT_GATT_CHARACTERISTIC(MY_UUID,
    BT_GATT_CHRC_WRITE,
    BT_GATT_PERM_READ,  ← PERM_WRITEが抜けている!
    read_cb, write_cb, NULL),

OK:
BT_GATT_CHARACTERISTIC(MY_UUID,
    BT_GATT_CHRC_WRITE,
    BT_GATT_PERM_READ | BT_GATT_PERM_WRITE,
    read_cb, write_cb, NULL),
```


## よくある問題: Notifyが届かない（CCCD未設定）

```
症状: iOS で setNotifyValue(true, for:) を呼んでいるが
      nRF52840側でbt_gatt_notify()を呼んでもデータが届かない

確認: Wiresharkで CCCD書き込み（Write to 0xXXXX, Value=0100）があるか確認

原因:
- BT_GATT_CCC マクロがサービス定義に含まれていない
- setCCDの Write がエラーレスポンスを返している

Zephyrでの正しいCCC宣言:
  BT_GATT_CHARACTERISTIC(TEMP_UUID, BT_GATT_CHRC_NOTIFY, ...),
  BT_GATT_CCC(ccc_changed, BT_GATT_PERM_READ | BT_GATT_PERM_WRITE),
  ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  PERM_WRITE を必ず付ける
```


## よくある問題: writeValue が失敗する (Write Without Response)

```
症状: iOSで .withoutResponse (Write Without Response) を使うと
      CanSendWriteWithoutResponse チェックなしに大量送信して失敗

解決:
func peripheral(_ peripheral: CBPeripheral,
                isReadyToSendWriteWithoutResponse: Bool) {
    if isReadyToSendWriteWithoutResponse {
        sendNextChunk()
    }
}
```


**まとめ**

| 症状 | 原因 | 対策 |
|---|---|---|
| 値が異常 | バイトオーダー | Little-endianに統一 |
| データが20Bで切れる | MTU未交換 | bt_gatt_exchange_mtu + 分割送信 |
| Writeが反映されない | PERM_WRITE不足 | GATTサービス定義を確認 |
| Notifyが届かない | CCCD未設定/PERM_WRITE不足 | BT_GATT_CCC + PERM_WRITE |
| WwoR失敗 | フロー制御無視 | isReadyToSendWriteWithoutResponse を待つ |
